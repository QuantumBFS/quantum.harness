# TEMPO 家族两种张量网络方案对比：PT-TEMPO+TEBD 链 (Fux 2023) vs. uniTEMPO (Link 2024)

——兼论 uniTEMPO 向多体系统推广的可行性

**对比文献：**

- **[Fux23]** G. E. Fux, D. Kilda, B. W. Lovett, J. Keeling, *Tensor network simulation of chains of non-Markovian open quantum systems*, Phys. Rev. Research **5**, 033078 (2023).
- **[Link24]** V. Link, H.-H. Tu, W. T. Strunz, *Open Quantum System Dynamics from Infinite Tensor Network Contraction*, Phys. Rev. Lett. **132**, 200403 (2024).（即 "uniTEMPO"）

---

## 1. 两篇文章各做了什么

### Fux23：空间维用 TEBD，时间维用 PT-MPO —— "先压浴，再拼链"

研究对象：N 个格点组成的一维链，**每个格点各自耦合一个独立的结构浴**（或链的两端耦合热库），格点间有最近邻耦合 K̂ₙ,ₙ₊₁。

方法骨架：

1. 对每个浴单独构造过程张量的 MPO 表示（PT-MPO，键维 ξ），用已有的 PT-TEMPO 有限网络收缩（OQuPy 实现）；
2. 链的幺智演化在 Liouville 空间做 Suzuki–Trotter 分解，得到标准 TEBD 网络；
3. 把每个格点的 PT-MPO "挂"到 TEBD 网络对应格点上，形成 **augmented MPS**（每个格点多一条通往浴记忆的时间腿）；
4. 逐行吸收网络，SVD 截断控制键维；用 "cap tensor" 在任意中间时刻抽出链的约化密度矩阵；插入左/右作用超算符即可算多时关联。

物理展示：N=5 XYZ 链单浴热化（用 FDT 验证，发现常用的两自旋 GKSL 驱动方案给出的双时关联是错的）；N=9 链处于温度梯度中、频率分辨有效温度 T(ω) 呈现低/中/高频三段行为；N=21 XY 链每点独立浴的扩散动力学。

### Link24：时间维用无限网络收缩 —— "一步收缩出半群传播子"

研究对象：**单个杂质型系统**（小 Hilbert 空间，维数 d）耦合高斯浴。

方法骨架：

1. 影响泛函（IF）精确写成一个二维张量网络（TEMPO 网络）；
2. 关键观察：给每个 b⁽ᵏ⁾ 张量的指标增加一个 "0" 维（Iₖ(0,·)=Iₖ(·,0)≡1）后，有限时 IF 可以从**无限时** IF 中通过在边界插零取出（F_M = F_N^{0…0,μ…}），且可用 ≥ N_c 个零把 IF 因式分解；
3. 于是收缩一个无限、时间平移不变的网络即可：把 "门" b⁽ᵏ⁾ 看作左右交替的最近邻耦合，用 **iTEBD（MPO 演化）** 沿反对角线方向收缩，只需 N_c² 次矩阵分解；
4. 结果是一个**均匀（uniform）MPO**：F_N = v_lᵀ f^{μ₁} f^{μ₂} … f^{μ_N} v_r，所有时间步共用同一个 χ×χ 张量 f，与 N 无关；
5. 半群结构给出短时传播子 Q(ν;j)(λ;i) = Σ_μ f^{μ}_{ij} U^{λμν}，其首本征向量直接给出稳态，全部本征值给出弛豫率谱 γₖ —— 不做长时间演化就能研究渐近物理与耗散相变。

物理展示：公共浴中两自旋的渐近并发度（concurrence）相图，证明二阶 Redfield 即使在弱耦合也给出系统性错误；sub-Ohmic 自旋-玻色模型的量子相变（谱方法 + 低频正则化外推，定出 α_c ≈ 0.1175）。

## 2. 结构性对比

| 维度 | Fux23 (PT-TEMPO + TEBD) | Link24 (uniTEMPO) |
|---|---|---|
| 解决的问题 | 多体空间扩展（N 点链） | 单杂质的时间维效率与稳态 |
| 浴的构型 | 每点独立浴（或端点浴）；**明确排除多点共浴** | 单一高斯浴 |
| IF/PT 的 MPO 形式 | 非均匀：O(N_c) 个不同张量，有限时网络逐次收缩 | 均匀：单一张量 f，任意时长平凡延拓 |
| 收缩算法 | 有限 2D 网络逐列收缩 + SVD | 无限网络 iTEBD，反对角线方向 |
| 时间结构 | 逐步传播，K 步后停止 | 半群传播子 Q，可谱分解 |
| 稳态获取 | 长时间演化到近似稳态 | Q 的首本征向量，直接给出 |
| 多时关联 | 原生支持（插超算符，含 OTOC） | 论文未展开，但过程张量框架同样支持 |
| 系统-浴强耦合 | 精确（PT 非微扰） | 精确（IF 非微扰） |
| 辅助自由度观点 | PT-MPO 键维 ξ = 非马尔可夫性的度量 | f 的键维 χ 自动生成"最优辅助自由度"，与 HEOM/赝模同构 |
| 代码 | OQuPy (Python) | iTEBD-TEMPO (GitHub: val-link) |

一句话：Fux23 解决了"空间维"的扩展，Link24 解决了"时间维"的最优收缩与稳态谱；两者处理的是同一个 PT-MPO 对象的不同侧面，天然互补。

## 3. 计算复杂度分析

记号：N_c = 浴记忆时间步数，N = 链格点数，K = 演化时间步数，d = 单点 Hilbert 空间维数，χ = 空间 MPS 键维，ξ = PT-MPO（浴记忆）键维，η = augmented MPS 有效键维（χ ≲ η ≤ χξ），Δ 或 δt = 时间步长。

### 3.1 构造浴的 IF/PT-MPO 的成本（单个浴）

| 方案 | 矩阵分解次数 | 存储 |
|---|---|---|
| 朴素有限网络收缩 (PT-TEMPO, 2018–2019) | O(N_c²) | O(N_c) 个 MPO 张量 |
| Cygorek et al. PRX 14, 011010 (2024) | O(N_c log N_c) | 同上 |
| **uniTEMPO (Link24)** | **O(N_c²) → 论文强调相对有限收缩的加速是数量级的；关键是有效算法只随 N_c 线性增长（"linear in the bath memory time"）** | **1 个张量 f（χ×χ per μ）** |

Link24 摘要明确宣称 "numerical scaling linear in the bath memory time"，相对此前最优的 O(N_c log N_c) 是质变；并且由于大 k 的 b⁽ᵏ⁾ 门是弱纠缠的，键维只在最后几步显著增长，iTEBD 收缩在精度/键维比上与有限收缩相当，但快数个数量级。

### 3.2 系统传播的成本

**Fux23（多体链）：** 总成本 **O(N · K · η³ d⁶)**。

- 来源：每步每键的 SVD 作用在最大 (ηd²)×(ηd²) 的矩阵上（附录 A 给出的收缩顺序把原始的 (χξd²)² 压到 (ηd²)²）；
- d⁶ = (d²)³ 来自 Liouville 空间局域维数 d² 的三次方；
- η 同时承载空间纠缠（χ，随动力学增长）与浴记忆（ξ，随非马尔可夫性增长），二者以**乘积**形式进入成本 —— 这是该方法的根本瓶颈：强非马尔可夫性 × 高纠缠多体态 = η 双重膨胀；
- 与标准 TEBD 一样适合并行（相邻键独立演化）。

**Link24（单杂质）：** 每步传播是 d²χ 维向量的矩阵乘法，成本 O(d⁴χ²) 每步，且与总时长无关地可以直达稳态（对 Q 做一次 χd² 维本征分解，成本 O((χd²)³)，一次性）。

关键不对称性：Link24 的成本随**系统维数 d² 指数**增长（对 N 个自旋 d = 2^N，每步 O(16^N χ²)），所以原生 uniTEMPO 只能处理"小系统 + 任意浴"；Fux23 的成本随**格点数 N 线性**增长，但只在浴可分解为每点独立浴时成立。

### 3.3 复杂度对照小结

| 瓶颈方向 | Fux23 | Link24 |
|---|---|---|
| 记忆时间 N_c | PT-MPO 构造 O(N_c log N_c)，传播中 ξ 进入 η³ | O(N_c)（最优），f 只算一次 |
| 总演化时长 K | 线性，且必须逐步走到稳态 | 稳态零边际成本（谱方法） |
| 格点数 N | 线性 O(N) | 指数 O(16^N) —— 致命 |
| 浴结构 | 每点独立浴 | 任意（单浴）高斯浴，含共浴集体耦合 |

## 4. uniTEMPO 推广到多体系统的可行性分析

### 4.1 朴素推广：整条链当作"系统" —— 不可行

直接把 N 自旋链视为 Link24 中的系统，则 Liouville 指标 μ 跑 4^N 个值，f^μ 是 4^N 个 χ×χ 矩阵，每步成本 O(16^N χ²)。N ≳ 5–6 即不可行。这条路没有出路，必须引入空间结构。

### 4.2 路线 A：uniTEMPO × Fux23 嫁接（每点独立浴）—— 高可行，基本是工程问题

Fux23 框架中每个浴的 PT-MPO 是一个可替换模块。用 uniTEMPO 的均匀 f 替换 OQuPy 的非均匀 PT-MPO：

- **收益 1（构造端）**：PT-MPO 构造成本从 O(N_c log N_c) 降到 O(N_c)，且内存从 O(N_c) 个张量降到 1 个 —— 对每点一个浴的 N 点链，总 PT 构造从 O(N · N_c log N_c) 降到 O(N · N_c)；
- **收益 2（稳态端）**：整条链的长时间行为可以用（空间）转移矩阵 ×（时间）半群传播子的双重均匀结构处理，有望避免"演化到稳态"的逐步传播，直接做谱分析 —— 这是 Fux23 完全不具备的能力（该文稳态靠长时间演化逼近，见附录 B 键维增长图 13）；
- **代价/风险**：augmented MPS 的收缩序列（Fux23 附录 A.2）依赖 PT-MPO 逐时步张量的显式形式，嫁接近似均匀 f 需要重写 cap tensor 与多时关联的插入方式；η 的 χξ 乘积瓶颈不因 PT 构造变快而消失。**这是最现实的近期路线，但没有克服任何物理上的根本障碍，只是更快、能到稳态。**

### 4.3 路线 B：公共浴集体耦合（challenge #123 的情形）—— 中等可行，需要新的张量结构

浴耦合集体算符 Ŝ = Σᵢ σ_zⁱ。此时 IF 依赖整条磁化路径 {s_k, s'_k}，权重

I = exp(−Σ_{k'≤k} (Σᵢ Δsⁱ_k) η_{k−k'} (Σⱼ Δsʲ_k'))

对所有 (i,j) 格点对因式分解 —— 在任一固定时间对 (k,k')，这是一个**空间上全连接的两体权重**。两个可利用的结构：

1. **IF 在空间方向是 MPO**：逐点插入零的技巧仍可在时间方向做；空间方向的全连接两体权重可写成键维 O(N_c) 的空间 MPO（这与 Gribben et al., PRX Quantum 3, 010321 (2022) 处理非加性/共享浴的思路一致）。于是完整的 "IF × 链传播" 是一个 (1+1)D 网络，时空两个方向都可 MPO 化 —— uniTEMPO 的 iTEBD 收缩原则上有二维推广（PEPS/CTM 式收缩），但成本和精度完全未被验证；
2. **简并压缩**：f^μ 只通过耦合算符本征值之差 (S_μl − S_μr) 依赖 μ，而 Ŝ 只有 2N+1 个不同本征值 —— IF 的不同"权重类型"数从 4^N 降到 O(N²)。可惜这只压缩了 IF 的指标类型数，系统的自由演化 U 仍然活在完整 4^N 维 Liouville 空间；且当 H_sys 含相互作用（Ising + 横场不保持总 S²）时无法约化到 Dicke 流形。所以简并压缩必须和空间 MPS 表示联用才有意义。

**根本风险**：Link24 的 iTEBD 收缩之所以高效，是因为大 k 的门弱纠缠（记忆衰减）。在多体共浴情形，浴不仅携带时间关联，还**介导空间上的有效长程相互作用**；IF 网络在时空两个方向的纠缠可能同时增长，单一均匀张量 f 的键维 χ 可能随 N 恶化。这正是原论文只做了单杂质、且 outlook 里只敢说 "IF-MPS hybrid" 的原因。

### 4.4 路线 C：Floquet-uniTEMPO（挑战 #123 的核心诉求）—— 研究级开放问题

Link24 的半群结构依赖严格时间平移不变性。周期驱动把它弱化为**周期平移不变性**：f 张量变成一个驱动周期内的有限循环序列 {f₁,…,f_M}，单周期传播子 Q_T = Q_{M}···Q_1 仍是时间无关的超算符，Floquet 稳态 = Q_T 的首本征向量，Mic­kiewicz–Link–Strunz (PRL 136, 200201, 2026) 在单自旋上已实现这一点。推广到多体的增量困难与 4.3 完全相同（共浴 IF 的空间结构），但额外多了一个有利条件：**只需在一个驱动周期内构造非均匀的张量序列，无限周期延拓是平凡的**。因此合理的实施顺序是：单自旋 Floquet-IF 复现（Tier 1，已有 Zenodo 数据可对照）→ 路线 A 的每点独立浴 Floquet 链（工程）→ 路线 B 的共浴小链 N=3–4（研究）。

### 4.5 可行性裁决

| 路线 | 可行性 | 主要障碍 | 性质 |
|---|---|---|---|
| A：uniTEMPO 替换 Fux23 的 PT 构造 | 高 | 收缩序列重写；χξ 乘积瓶颈依旧 | 工程改进 |
| B：共浴集体耦合 + 空间 MPO | 中 | IF 时空双方向纠缠增长，χ(N) 标度未知 | 方法学研究 |
| C：B + 周期驱动 (Floquet) | 中（B 成立则 C 几乎免费） | 同 B | challenge #123 的正餐 |

**结论**：uniTEMPO 向多体的推广不存在原理性禁令 —— 影响泛函的"MPO-in-time"与链的"MPS-in-space"天然拼成 (1+1)D 网络；真正的未知数是共浴情形下均匀 IF 张量的键维随 N 和耦合强度的标度。这个问题只能用数值实验回答，而回答它的最小可行路径就是 challenge #123 的 Tier 1 → Tier 2 路线。
