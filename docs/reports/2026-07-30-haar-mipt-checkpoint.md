# Haar 随机电路 MIPT：本机数值 checkpoint

## 计算方案

- 测量率固定为 `p = 0.168`。
- 系统尺寸为 `L = 8, 10, 12, 14, 16, 18`，周期边界条件。
- 每条轨迹采用 `4L` 个 half-layer 热化，再记录 `24L` 个 half-layer。
- 每个尺寸分别计算 16 条全局 Haar 初态轨迹和 16 条随机乘积初态轨迹；两族在无序平均中各占严格的 `1/2` 权重。
- 状态使用 `complex128` exact state vector；两比特 Haar 门以 matrix-free 方式作用；逐格点执行 Born-sampled Z 投影测量。
- 每个尺寸的自由能密度估计为记录负对数 Born 概率除以 `L × record_steps`。
- 主拟合先对每个 `L_min = 8, 10, 12, 14` 做加权的 `f_L = a + m/L²`，再将窗口斜率按 `m(L_min) = m_∞ + b/L_min²` 外推；使用 `c_eff = -6m_∞/(π α)` 和 `α = 0.81`。
- 误差来自 1000 次整轨迹 bootstrap；另用包含 `L⁻⁴` 项的加权拟合作稳定性检查。

## 拟合结果

- 双重窗口外推：`c_eff = 1.5592`。
- 整轨迹 bootstrap 标准误：`0.9549`。
- bootstrap 95% 区间：`[-0.3138, 3.4316]`。
- `L⁻⁴` 稳定性拟合：`c_eff = 1.4954`。
- 两种拟合的差为 `0.0638`，但这不能代表总系统误差，因为窗口斜率本身不稳定。

四个窗口的 `m` 分别为 `-0.00463, -0.15402, -0.37488, -0.45912`；其强烈的 `L_min` 漂移导致二次外推得到 `m_∞ = -0.66128`。作为比较，若文献值 `c_eff ≈ 0.25` 且 `α = 0.81`，预期斜率只有约 `-0.106`。当前每个 `f̃_L` 的误差约为 `4×10⁻⁴` 到 `10⁻³`，与需要分辨的有限尺寸信号同量级。

因此，本 checkpoint 验证了完整的生成、恢复、聚合、拟合和 bootstrap 流程，但 **不能据此宣称复现了文献的 `c_eff ≈ 0.25`，也不能把 1.56 解释为新的物理结果**。

## 性能与下一步

入口必须在任何 NumPy/Matplotlib 导入之前设置 `OMP_NUM_THREADS=1`、`MKL_NUM_THREADS=1`、`OPENBLAS_NUM_THREADS=1` 和 `NUMEXPR_NUM_THREADS=1`。否则 4 个 worker 会各自启动约 4 个数值线程，`L=18` 单条轨迹从约 80 秒恶化到约 244 秒。

下一步应在集群上把每族样本数至少提高到 512，并保持整轨迹 bootstrap。按修正后的本机吞吐量粗略估计，512 条/族在 8 workers 上约需数小时，因此不应继续作为本机短作业。还应在正式生产前修复 worker 异常时“先保存其他成功结果再汇报失败”的调度恢复缺口。
