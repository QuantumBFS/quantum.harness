一、背景：强驱动 + 强耗散的量子系统

1.1 为什么这个问题重要

周期驱动（例如用激光持续照射一个量子系统）是现代量子工程的核心手段——通过精心设计驱动，可以"按需合成"平衡态不存在的物质相，这就是 Floquet 工程。但周期驱动会持续向系统泵入能量（做功），系统通常不断升温，这就是 Floquet 工程面临的核心障碍——加热问题。

要获得稳定的长时间演化，系统必须把驱动泵入的能量排放到环境（热浴）中去。此时驱动与耗散的竞争会稳定出一种非平衡稳态（nonequilibrium steady state, NESS）：系统状态不再变化（在频闪意义下周期重现），但能量持续地从驱动场流向热浴。这股能量流（热流）有多大、以哪些频率离开系统，是理解这类系统物理的关键可观测量，也直接关联量子热力学与量子器件的实际问题。

理论描述这件事并不容易。教科书做法（Redfield / Lindblad 主方程）假设浴"没有记忆"（马尔可夫近似）、系统-浴耦合弱（Born 二阶微扰）。但当耦合强、浴的关联时间长（非马尔可夫）、驱动又强又快时，这些近似逐个失效——而目前恰恰缺乏一个既精确又好用的理论工具。

1.2 论文做了什么（Mickiewicz, Link & Strunz, PRL 136, 200201 (2026)）

论文的核心思想是影响泛函（influence functional, IF，也称过程张量）：把环境对系统的全部影响——包括任意长的记忆——精确编码进一个多时间关联泛函里。这样环境自由度被完全积掉，系统的任何多时间关联函数都能由 IF 与系统的局部操作算出，不需要任何马尔可夫或弱耦合近似。代价是：一般系统的 IF 是一个指数大的对象。

论文的三个关键进展：

  • 时间方向的均匀 MPO 表示：对于高斯玻色浴（浴关联函数只依赖时间差），IF 在时间方向上是"平移不变"的，可以压缩成键维有限的均匀矩阵乘积算符（MPO），用 iTEBD 无限收缩一次得到。记忆越深，键维越大，但增长是可控的。
  • Floquet 推广（Floquet-IF）：对周期驱动的系统，驱动使 IF 张量以驱动周期 M 为周期重复。把一周期的 M 个张量收缩起来，得到一个有效的时间无关 Floquet 传播子 Q_F——它扮演"耗散版 Floquet 哈密顿量"的角色：其主本征矢直接给出频闪稳态，无需跑长时间暂态。
  • 频率分辨热流：论文推导并计算了热流密度谱 j̄(ω)——稳态下浴在每个模式频率 ω 处吸收能量的速率。它由两部分组成：位于驱动谐波 nω_d 处的相干 δ 峰（系统"弹性"地向浴放能），和一片非相干的连续谱。总热流 Ī = ∫ j̄(ω) dω 恰好等于驱动平均功率 P̄（能量平衡），为计算提供了严格的自洽检验。
图 1（论文原图）：周期 Floquet 影响泛函的量子线路表示
（引自论文 Figure 1）(a) 开放系统多时间关联函数的线路表示：全局幺正 𝒰_n 因周期驱动而周期重复；(b) 压缩后的周期 MPO 表示：全局幺正被压缩张量 Q_n 替代，周期结构保留；(c) 把一个周期内全部 Q_n 收缩得到有效时间无关传播子 Q_F，描述频闪演化并定义频闪 Floquet-IF。这张图概括了论文方法的全部要点；我们的工作就是把这张图的框架从单体推到多体。

论文的边界也正是挑战的起点：该方法把时间方向的张量网络挂在"系统"上，系统本身（单体自旋，或两个比特）是用普通矩阵表示的。要把系统换成一条 N 自旋的相互作用链，系统维数 2^N 指数爆炸，论文的方法本身没有回答怎么做——这正是 Challenge #123 要求我们探索的方向。

二、模型

2.1 论文的单体模型（复现对象）

总哈密顿量 H(t) = H_sys(t) + H_env + H_int，其中：

H_sys(t) = (Ω/2) σ_x + ε_d cos(ω_d t) σ_z   （横场驱动；论文图 2/3 横场组）
H_sys(t) = (Ω/2 + ε_d cos(ω_d t)) σ_x   （纵场驱动；论文图 3 纵场组）
H_env = Σ_λ ω_λ b_λ†b_λ，   H_int = S Σ_λ g_λ (b_λ† + b_λ)，   耦合算符 S = σ_z

浴为 T=0 Ohmic 浴，谱密度 J(ω) = αω e^{−ω/ω_c}，对应解析浴关联函数 η(t) = αω_c²/(1+iω_c t)²。复现统一参数：α = 0.05，ω_c/Ω = 2.5，δt = π/(60Ω)。

2.2 我们的多体模型（推广对象）

一维 N 自旋驱动斜场 Ising 链，链的左端点（站点 1）耦合同一个 T=0 Ohmic 浴：

H_S(t) = J Σ_{i=1}^{N−1} σ_z^i σ_z^{i+1} + h_x Σ_i σ_x^i + (h_z + A cos ω_d t) Σ_i σ_z^i
H_int = σ_z^1 Σ_λ g_λ (b_λ† + b_λ)   （浴只耦合站点 1；谱密度与单体相同）

默认参数：J = 0.5，h_x = 0.5（对应论文 Ω = 1），h_z = 0.3，A = 1，α = 0.05，ω_c = 2.5，δt = π/60。选择边界耦合的理由：浴的影响泛函只对站点 1 的路径敏感，其键维 χ_b = 41 与链长 N 无关——这是多体推广可行的支点（见 5.1）。初始态 |↑⋯↑⟩，t 演化到 NESS 后测量。

三、问题提出

论文回答了单体问题；Challenge #123 要求回答多体问题。我们把挑战具体化为三个问题：

  • Q1：多体系统中热流谱会是怎么样的？单体的 j̄(ω) 是孤立锐线加 δ 峰——两能级系统只有一个 Bohr 频率。多体系统有 2^N 个能级、密集的跃迁通道，谱的形状、δ 峰的命运、连续谱的来源，都没有现成答案。
  • Q2：谱如何随体系尺寸重新分布？总热流 Ī(N) 如何增长？谱的重量在相干通道与连续通道之间如何随 N 转移？浴只接在端点，输运瓶颈会留下什么有限尺寸签名？
  • Q3：非马尔可夫性的影响如何？若用马尔可夫主方程（Floquet–Redfield）算多体热流，与精确结果的偏差有多大？偏差依赖驱动频率和体系尺寸吗？——这决定了大量现存马尔可夫文献结论的可信边界。

五、第二部分：多体推广结果

以下为本组独立工作：把 Floquet 影响泛函方法从单体推广到相互作用多体链，并首次计算多体的频率分辨热流谱。

5.1 算法：边界浴增广 MPS

把 N 自旋链整体当作 IF 的"系统"，耦合算符维数 4^N，不可行。我们的方案利用"浴只耦合边界站点 1"这一结构，四个要点：

  • 记忆腿只挂边界张量：IF 是时间方向的均匀 MPO（键维 χ_b = 41，与 N、ω_d 无关），只对站点 1 的演化路径敏感。把它作为一条"记忆腿"挂在空间 MPS 的第一个张量上，其余站点是普通密度矩阵 MPS 张量。空间键从不承载 χ_b，避免了早期方案中空间键维 × 记忆键维的乘积瓶颈。
  • 帽式 MPS 计算观测量：所有可观测量（⟨σz⟩、能量、纯度、关联函数）都在张量网络形式上收缩得到，从不构造 4^N 的完整密度矩阵——这是能算到大尺寸的关键。
  • 两点关联函数测热流：热流谱 j̄(ω) 需要稳态两点关联 ⟨S(t+τ)S(t)⟩。做法：先把链演化到 NESS；在一个驱动周期内记录 M 个完整张量网络快照（含记忆腿）；每个快照左乘 S 后再传播 τ；周期平均后作 Fourier 积分得连续谱；⟨S(t)⟩ 的不衰减振荡给出 δ 峰权重。IF 记忆腿自动把浴关联带过算符插入点，无需额外处理。
  • 含时 Floquet–Redfield 对照：平行实现不含 Magnus 展开的含时 Redfield 方程（RK4 演化 + 浴记忆滚动窗口），演化中探测密度矩阵的半正定性，作为马尔可夫近似的独立对照组（Q3）。

图 5 图注　(a) 频率分辨热流谱 j̄(ω)：黑色为单体——能量只以系统特征频率的锐线离开系统（对应两能级系统唯一的 Bohr 频率 ω≈1.17 及其驱动边带）；红色为 N=4 链——16 个能级的密集 Bohr 频率把谱熔成 ω≈0.5–3.5 的连续带，谱总重（积分面积）明显增大。(b) δ 峰权重 c_n：ω = ω_d 处的相干峰从 0.028 掉到 0.0024（−92%）——相互作用把"弹性放能"的相干通道几乎完全打散到非相干连续谱。(c) 能量平衡：独立计算的驱动功率 P̄ 与谱积分 Ī 相对偏差 0.03%——计算通过最严格的内在自洽检验。物理：这就是 Q1 的首个答案——多体热流谱是"线熔成带、相干重量转非相干"。
图 6（M5a）：尺寸标度——线到带的演化与两个标度律（ω_d = 2.5，N = 1,2,3,4）
图 6 图注　(a) N=1→4 的 j̄(ω) 叠放：线谱逐步带化的完整过程。(b) 总热流 Ī(N)：0.029 → 0.065 → 0.062 → 0.066——N=2 之后基本不再增长。浴只接在端点，加更多自旋并不增加耗散出口；内部自旋的能量须穿过整链才能到达浴，形成边界输运瓶颈。(c) 相干峰权重 c_1(N)（对数坐标）：随 N 几何衰减（每加一个自旋缩小 2–3 倍），支持热力学极限下相干峰消失。物理：这是 Q2 的预览答案——谱重量从相干通道向非相干通道转移，总量被瓶颈饱和。N=5,6 的确认数据在集群计算中。
图 7（M5c）：精确 vs 马尔可夫——同参数基线对照与正定性监控
图 7 图注　(a) 三个同参数对照点上，精确（增广 MPS）与含时 Floquet–Redfield 的总热流对比：N=1 与 N=2（ω_d=2.5）上两者吻合到 2%（比值 F = Ī_exact/Ī_RM = 0.98）；ω_d=10 的高频点上两者都给出 ~10⁻⁴ 的微小热流，同样一致。含义：在我们已扫描的参数点上，马尔可夫主方程对总热流是准确的——Q3 不能先验假定马尔可夫近似失效；真正的考验是驱动频率扫过浴窗内共振通道时的表现（全 ω_d 网格扫描在集群进行）。(b) 正定性监控：Redfield 演化不保证密度矩阵半正定，我们以最小本征值 min λ(ρ(t)) 全程监控。ω_d=2.5 两点恒正；ω_d=10 点在早期出现 −3×10⁻³ 量级的负值（恰为二阶微扰 O(α²) 的预期量级），随后回到零附近。该监控将用于圈定 Redfield 在多体 + 强驱动区的可信边界。

5.4 多体结果总结

相互作用导致热流密度谱的峰变宽并趋于消失——单体的离散锐线（Bohr 频率 ± 驱动边带）在多体链中因能级稠密与相互作用退相位而展宽、交叠、熔成连续带；位于驱动谐波处的相干 δ 峰权重随体系尺寸几何衰减，趋于消失。多体会增加热流，但由于输运瓶颈，热流的增加随系统尺寸快速饱和——总热流从 N=1 到 N=2 增大约一倍，但 N=2 之后基本持平：浴只耦合链的端点，耗散出口固定，内部自旋的能量须穿过整链才能排出，链越长新增自旋对总热流的贡献越小。

六、展望

  • 集群扫描在途：N=5,6 补齐尺寸标度；23 个驱动频率 × N=4,6 的全网格——沿共振通道定位热流极大，检验浴窗边缘 ω_d ≈ ω_c 处谱重开/关；同参数的 Floquet–Redfield 全网格对照，输出谬误因子 F(ω_d, N) 与正定性相图（Q3 的定量答案）。
  • 共振谱学：ω_d 扫描使浴成为链的谱仪——j̄(ω) 的峰位追踪 H_0 本征跃迁，直接检验"浴修饰共振"是否偏离裸 Bohr 频率（超出 ED 预言的物理）。
  • 输运分类：更大的 N 上判定边界瓶颈律属于弹道（Ī 饱和）还是更慢输运（Ī 衰减）——这决定边界浴方案能推到的体系尺寸上限。
  • 集体耦合：把浴从边界耦合改为全链集体耦合 S = Σσ_z^i，对应 Challenge #123 的原始表述（Dicke 型超级辐射通道进入热流谱）。
