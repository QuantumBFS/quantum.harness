# RBIM Nishimori-Point Random Transfer Design

## Objective

Measure the effective central charge of the square-lattice bimodal random-bond
Ising model at the Nishimori point with direct spin-basis random transfer
operators. Use cylinder circumferences `L = 8, 10, 12, 16, 20`. The first
deliverable uses only the leading Lyapunov exponent required for the quenched
free energy; the subleading Lyapunov spectrum is deferred.

## Model and conventions

Each nearest-neighbor bond is independent and takes the values

\[
J_{ij}=\begin{cases}
-1,&\text{with probability }p_c=0.1092212,\\
+1,&\text{with probability }1-p_c.
\end{cases}
\]

The dimensionless coupling is fixed by the Nishimori-line condition

\[
K_N=\frac{1}{2}\log\frac{1-p_c}{p_c}.
\]

The geometry is an infinitely long cylinder: the transverse direction has
periodic boundary conditions and circumference `L`, while the transfer
direction tends to length `M -> infinity`. Horizontal and vertical bonds are
sampled independently from the same bimodal distribution.

For a source row `sigma` and destination row `sigma_prime`, one random transfer
step is

\[
T_m(\sigma',\sigma)=\exp\left[
K_N\sum_i J^\tau_{m,i}\sigma'_i\sigma_i
+K_N\sum_i J^x_{m,i}\sigma'_i\sigma'_{i+1}
\right].
\]

Putting each horizontal bond on its destination row changes only boundary
terms at finite `M` and fixes an unambiguous streaming implementation.

## Matrix-free transfer action

The state vector has dimension `2**L`; no dense transfer matrix is formed.
For every random row:

1. Sample `L` vertical bond signs and `L` horizontal bond signs.
2. Apply the vertical factor as a product of `L` local two-by-two matrices
   using reshape-and-butterfly operations on the row-state vector.
3. Multiply by the diagonal horizontal Boltzmann weights of the destination
   row.
4. Divide by the Euclidean norm and record the logarithm of that norm.

The horizontal spin products for all bit-encoded row configurations may be
precomputed as an `int8` array. At `L = 20` this costs about 20 MiB, while two
float64 work vectors cost about 16 MiB. The dominant cost is
`O(M * L * 2**L)` memory-bandwidth work, not storage.

Only scalar normalization is used. This is the ordinary power method for the
top Lyapunov exponent, not the Gaussian-QR free-fermion method and not a
multi-vector QR calculation.

## Quenched free energy and statistics

Starting from a uniform positive normalized vector, discard `50*L` rows as
burn-in. For retained rows, accumulate

\[
g_m=\log\left\|T_m v_{m-1}\right\|,
\qquad
\Lambda_0(L)=\lim_{M\to\infty}\frac{1}{M}\sum_m g_m.
\]

The reduced quenched free-energy density is

\[
f_L=-\frac{\Lambda_0(L)}{L}.
\]

Retained increments are grouped into contiguous blocks of length at least
`100*L`. Block means, rather than individual rows, define the standard error,
so correlations generated by the evolving boundary vector are included.
The raw block means, seed, number of retained rows, burn-in, and achieved
standard error are saved for every width.

The run has two stages:

1. A short pilot for all five widths measures wall time and block variance.
2. The measured variance estimates the rows required to reach a target
   standard error of `1e-4` in `f_L`. A local continuation is launched only
   when the projected total wall time remains below approximately ten minutes;
   otherwise the pilot-quality result and projected cost are reported without
   silently extending into a multi-hour local run.

The `1e-4` target is an accuracy budget, not a guaranteed result. The achieved
error is always reported and propagated into the central-charge fit.

## Central-charge extraction

The primary weighted fit is

\[
f_L=f_\infty-\frac{\pi c_{\mathrm{eff}}}{6L^2}
+\frac{a}{L^4}.
\]

The fit uses the five requested sizes and block standard errors as weights.
Two stability variants are also recorded:

- all sizes with only the `L^-2` correction;
- `L = 10, 12, 16, 20` with both `L^-2` and `L^-4` corrections.

Statistical uncertainty is obtained by resampling independent block means for
each width and refitting. The spread among the three fit forms is reported
separately as a finite-size fit envelope; it is not combined with the
statistical error as though the two had the same origin.

## Files and artifacts

Implementation follows the existing clean-Ising split:

- `scripts/random_bond_ising_transfer.py`: bond sampling, matrix-free row
  action, scalar normalization, pilot and streaming block output.
- `scripts/random_bond_ising_analysis.py`: block statistics, weighted
  finite-size fits, resampling, plots, and command-line orchestration.
- `scripts/tests/test_random_bond_ising_transfer.py`: small-width dense oracle,
  all-ferromagnetic row check, validation, and seed reproducibility.
- `scripts/tests/test_random_bond_ising_analysis.py`: synthetic central-charge
  recovery, block error propagation, and artifact checks.
- `results/random_bond_ising_nishimori/`: raw blocks, per-width summaries,
  central-charge fit JSON/CSV, runtime projection, and finite-size plot.

The runnable command exposes all sampling controls explicitly and flushes a
progress estimate after every completed block.

## Verification and stopping rules

Before the production run:

- compare matrix-free row action with an independently constructed dense
  transfer matrix at small `L` for fixed random bonds;
- verify the Nishimori coupling and antiferromagnetic-bond probability;
- verify identical raw blocks for identical seeds;
- verify the central-charge sign and normalization on synthetic data;
- run the existing clean-Ising tests to ensure the new code does not alter the
  established `c = 1/2` benchmark.

The result is reported as a measurement only if every requested width has a
finite leading exponent and a block error estimate. If the `L = 20` pilot
projects an impractical raw-spin runtime, the calculation stops with a
quantified precision/cost report; switching to Gaussian-QR then becomes a
separate user-approved step. No subleading Lyapunov exponents are attempted in
this stage.
