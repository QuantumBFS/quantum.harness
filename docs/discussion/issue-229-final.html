Moment-SDP block structure

The proxy compares one dense PSD cone with the character-sector cone dimensions. CHSH uses blocks 4+1 from a five-word order-1 basis; the Z₂×Z₂ instance uses 6+3+2+2 from a 13-word order-2 basis.

What was implemented now

  • An independent Julia NC specification for self-adjoint ±1 generators with explicitly declared cross-site commutations.
  • Word enumeration and normalization, moment keys, and the affine pencil Mᵤᵥ(y)=ynormalize(reverse(u)v).
  • Automatic lifting of Z₂k generator signs to word characters and rejection of non-invariant Hamiltonians. The dense hierarchy creates every real moment key and does not impose symmetry zeros in advance; only the reduced hierarchy group-averages non-invariant moments to zero.
  • JuMP/Mosek dense and reduced formulations use the same affine rule Muv(y)=ynormalize(reverse(u)v). Dense constrains the complete affine PSD pencil, while reduced constrains its character-sector affine PSD blocks.
  • Deterministic CHSH order-1 and two-site Pauli-style order-2 tests, reconstructed-matrix PSD checks, and Python integration into make test.

Scope

The narrowed finite-Abelian NC moment-SDP milestone is complete; the general issue #229 is not claimed complete. The implementation covers real order-1/2 moment matrices for self-adjoint ±1 generators and Z₂k sign actions. It does not yet provide general polynomial localizing matrices, complex moment data, non-Abelian permutation symmetry, SU(2), or a higher-order scalable hierarchy.
