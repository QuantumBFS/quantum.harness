## 一、这道题要求什么

### 比赛 Issue 的原文要求

Issue #232 由王杰（AMSS 中科院）和刘金国（HKUST-GZ）发布，题目是：

> 利用 moment-SOS / SOHS 层级，对 arXiv:2310.00612 Table 4 中的图，
> 给出量子图参数 β(G) 的**严格上界证书**。

翻译成大白话：

- 有一篇论文（arXiv:2310.00612）列了 43 个数学问题（图）
- 论文解决了其中 18 个，**剩下 25 个是开放的**
- 你的任务：解决这 25 个中的尽可能多
- "解决"的标准：不是数值近似，而是**精确数学证明**

### 什么叫"精确证书"

打个比方：

- 数值结果："我用计算器算出来 β ≤ 2.0000001"——这不是证明
- 精确证书："我构造了一个 45×45 的有理数矩阵，它的每个元素都可以用分数精确表示，
  并且可以验证它是正定的——这**证明**了 β ≤ 2"——这才是证明

区别在于：数值结果可能有误差，精确证书**不依赖数值精度**（纯数学推导）。

### 评分标准

| 级别 | 要求 | 难度 |
|------|------|------|
| 精确闭合 | 证明 β = α（上界 = 下界） | ★★★★★ |
| Hope signal | 上下界差距 < 0.000001 | ★★★★ |
| 收紧上界 | 比论文给的更紧 | ★★★ |
| 量子优势 | 发现 β > α 的例子 | ★★★★ |

## 二、背景：这个问题为什么有意思

### 从"量子比经典强多少"说起

想象一个游戏：你和朋友分别拿到一些信息，要合作完成任务。
- **经典策略**：你们只能用普通方式（比如提前商量好）
- **量子策略**：你们可以共享量子纠缠

问题是：**量子策略最多比经典好多少？**

数学家把这个"最多好多少"编码成了一个数字 β(G)。
- 如果 β(G) = α(G)（经典最优），说明量子**没有优势**
- 如果 β(G) > α(G)，说明量子**确实更好**

### 为什么难

计算 β(G) 需要解一个"非对易多项式优化"——变量是矩阵（不对易），
约束是多项式等式。这比普通的线性规划或二次规划难很多。

目前最好的方法是 **SOHS 层级**（Sums of Hermitian Squares）：
- Level 1：用小的矩阵近似 → 得到松的上界
- Level 2：用更大的矩阵 → 更紧
- Level 越高越紧，但计算量指数增长

**难点**：即使数值上算出来了 β ≈ 2，要把它变成**精确证明**
（用分数而非小数），需要额外的代数技术。很多图在这一步卡住了。

## 三、比赛过程

### 阶段 1：搭建验证管线

**目标**：先确认"我的代码能正确验证一个已知答案"。

用 CHSH 不等式（量子信息最简单的例子）做控制实验：
- 种子代码给出一个已知的 SOHS 证书
- 验证器独立检查：225 条数学恒等式 + 45 个正定性条件
- 全部通过 → 管线工作正常

这一步不产出新结果，但确保了后续实验的可信度。

### 阶段 2：OmniEvolve 进化搜索

**目标**：让 AI 自动搜索"哪些数学约束能让上界更紧"。

具体做法：
- 种子代码只有最基本的约束（level-1），给出上界 2.00249
- OmniEvolve 让 LLM 提出"添加这些三次约束试试"
- 沙箱运行 SDP 求解器，看新约束是否收紧了上界
- 如果收紧了 → 保留；如果没收紧或崩了 → 丢弃

**结果**：
```
第 0 代：上界 2.00249（种子）
第 2 代：上界 2.00046（AI 发现了有效的三次约束！）
第 9 代：上界 2.00017（AI 的极限）
第 10-20 代：停滞（AI 无法再改进）
```

**AI 的贡献**：第 2 代的跃升（2.00249 → 2.00046）是 LLM 真正发现的——
它找到了哪些三次约束组合能有效收紧上界。这是 Agent 手动搜索需要花很长时间的。

**AI 的局限**：第 9 代之后完全停滞。因为进一步改进需要更深的数学结构
（odd-hole 不等式、对称性分解），这不是"搜索"能解决的，需要"发明"。

### 阶段 3：Agent 精确化

**目标**：把 AI 找到的数值结果变成精确数学证明。

AI 给出的是小数（2.00017...），不能直接当证明用。Agent 执行：
1. 把小数舍入为分数（2.00017 → 20003/10000）
2. 用精确分数算术重建整个代数
3. 验证 225 条恒等式全部成立
4. 验证 45×45 矩阵的正定性（LDL 分解，45 个主元全部为正）

**关键判断**：选择 SCS 求解器（ADMM 算法）而非 Clarabel（内点法）。
原因：Clarabel 在这类奇异问题上会报"无解"（假阴性），而 SCS 能给出正确答案。
这个发现完全来自 Agent 实验——OmniEvolve 不会去比较不同求解器的行为。

### 阶段 4：批量闭合

**目标**：不逐图进化，而是发现"哪些图可以用同一方法批量解决"。

**关键洞察**（Agent 做出的）：
- 所有完全图 $K_n$：level-1 就能闭合（对称性保证）
- 所有完全二部图 $K_{m,n}$：level-1 就能闭合
- 所有偶圈 $C_{2k}$：level-1 就能闭合

这意味着**一次发现给出无限多个精确常数**——比逐图进化高效 100 倍。

然后对剩余的高对称图（Petersen、Schläfli、超立方体等）逐个处理。

### 阶段 5：Table 4 开放问题进攻

**目标**：直接进攻论文留下的 25 个开放问题。

做法：
1. 遍历所有 103 个 $\alpha=2$ 的 7 顶点图，用 level-2 SDP 筛选
2. 发现 **45 个图数值上可闭合**（$\beta \leq 2 + \varepsilon$）
3. 其中 6 个图含有 $C_5$ 子图（odd hole）——加入 odd-hole 不等式后获得正 margin
4. 正 margin 意味着可以精确有理化→ **6 个 Table 4 开放问题首次闭合**

| 图 | 边数 | odd holes | margin |
|----|------|-----------|--------|
| atlas782 | 12 | 4 | 2.0 |
| atlas859 | 13 | 2 | 0.5 |
| atlas888 | 13 | 2 | 0.5 |
| atlas927 | 14 | 1 | 0.44 |
| atlas942 | 14 | 2 | 0.5 |
| atlas990 | 15 | 1 | 0.44 |

剩余 39 个无 odd hole 的图：对偶奇异，需要 level-3 或对称性约化。
已启动 OmniEvolve 进化尝试（atlas961，搜索 degree-3 基词）。

### 阶段 6：前沿探索

**atlas#669**（一个特别难的 7 顶点图）：
- Level-2 SDP 给出 β ≤ 2.0000000027（离精确值 2 只差 0.000000003）
- 但精确闭合（β ≤ 2）在数学上被阻碍：对偶矩阵必须奇异，无法有理化
- 最终给出"hope signal"：β ≤ 2 + 10⁻⁸（精确证书，但不是完全闭合）

**graph33 结构性困难分析**：
- 分析了为什么这张图**在标准 SOHS 框架下尚未实现**精确闭合
- 原因：最优对偶含 √5（无理数），排除了有理证书的存在性
- 这是一个负面结果，但有数学价值（告诉后续研究者"别在这个方向浪费时间"）

## 五、反思与意义

### OmniEvolve 能做什么、Agent 能做什么

| OmniEvolve 进化做了 | AI Agent 数学工程做了 |
|---------|---------|
| 搜索有效的约束组合（gen=2 跃升） | 判断哪些图属于同一族 |
| 在已知框架内优化参数 | 选择正确的求解器（SCS vs Clarabel） |
| 快速试错（45 次评估，几小时） | 执行精确有理化（约束消元 + 舍入） |
| | 分析结构性困难（需要数学洞察） |
| | 发现“无限族闭合”策略（需要抽象思维） |

**核心教训**：OmniEvolve 是强大的“搜索力放大器”，但代数工程判断（选择什么方法、如何精确化）由 Agent 完成。
最好的结果来自**进化搜索 + Agent 数学工程**的协同模式。

### 对 #133（Problem Factory）的启示

1. **求解器需要连续梯度**：#232 成功是因为"上界从 2.00249 → 2.00017"
   给了 AI 明确的改进方向。如果评分是二值的（对/错），AI 就无法学习。

2. **精确验证门是核心基础设施**：如果没有"纯分数算术验证器"，
   AI 可能会作弊（直接输出 upper=2.0），或者无法信任进化输出的数值结果。

3. **批量策略 > 逐个进化**：一次发现"所有完全图都能闭合"
   比进化 100 代找单个图的解高效得多。问题生成器应该优先发现这种结构。
