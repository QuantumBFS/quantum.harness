## 2. What changed relative to the proposed approach

The issue proposes: CrystalFormer prior + pymatgen cosine-similarity reward + PPO minimising
`F = E_{X~q}[−r(X)] + τ·KL(q‖p)`, with the space group *discovered* by the model rather than
assumed. Four of those five choices did not survive measurement.

| | proposed | built | why |
|---|---|---|---|
| **reward** | cosine similarity | EMD + non-negative Chebyshev background | cosine **inverts** on noisy data (§3) |
| **cell** | generated by the model | classically indexed from peak positions | the data fixes the cell 500–1600× better than the motif (§4) |
| **space group** | discovered as first token | conditioned on, from systematic absences | free (`--spacegroup`), and worth 67× on baddeleyite |
| **search** | PPO optimising q(X) | best-of-N + MLFF + deterministic refinement | never needed (§6) |
| **prior** | CrystalFormer | CrystalFormer — **unchanged** | the one component that proved essential |

The generative prior is the part that works. The variational machinery built around it is the
part that turned out to be unnecessary.

---

## 3. The reward had to change: cosine is unsafe

**Cosine similarity inverts on noisy data.** At 10⁴ counts with 10 % background its motif signal
goes *negative* — anatase −0.00185, quartz −0.00035 — meaning the wrong structure scores better
than the true one. That is not a weak reward but a sign-flipped one, and any optimiser would move
away from the answer.

The fix is what a Rietveld refinement does: model the observation as

```
obs(x) ≈ s·sim(x) + Σ_k c_k T_k(x)        (T_k Chebyshev, s ≥ 0)
```

solved by weighted least squares with Poisson weights, then compare with the 1-Wasserstein
distance `∫|CDF_a − CDF_b| dx`. Unlike a pointwise inner product, EMD charges the *transport
cost* of moving intensity between peaks — which is exactly what a motif error does.

Motif-signal gain over cosine, across four structures: **19–3000×**, and it never inverts.
Background order 4–6 is the operating point (order 0 fails outright; order 20 begins absorbing
real structure).

Intensity reweighting alone does not work — sqrt, log and high-angle-only windowing all *reduce*
motif signal. Modelling the background is what matters.

---

## 4. The cell must come from the data, not from a model

Two measurements force the architecture.

**The pattern constrains the lattice far more tightly than the motif.** At matched rms atomic
displacement on rutile, a lattice error costs 500–1600× more reward than a motif error: peak
positions depend only on the lattice metric, while the motif enters solely through intensities.
Whatever determines the cell should therefore be the data.

**A force field is not accurate enough to set it.** Relaxing each *true* structure with the cell
free — so any drift is pure model error — 6 of 7 targets exceed the tolerance below, CuO by
**19.3 %**. A force field seeks an energetic minimum, carrying exchange-correlation error and
describing a static 0 K structure, while the measurement is of a thermally expanded cell.

**How accurate must the cell be?** Refinement tolerates ≥ 5 % cell error at 1–4 degrees of
freedom, but only ~0.2–0.5 % at 9, dying by 1 %. More free coordinates let the optimiser absorb a
wrong cell by distorting the motif, manufacturing a well-fitting wrong answer.

**Classical indexing clears that bar by an order of magnitude.** Given the space group, the
problem is *linear in the reciprocal metric tensor* in Q-space, so assigning trial indices to a
few low-angle lines gives an exact linear solve (the TREOR strategy). Every peak indexed on all
seven targets, residuals 0.005–0.015°, **cell errors 0.003–0.019 %**.

Blind global optimisation does not work here: it finds exact supercells, which explain every
observed line while predicting many unobserved ones. The de Wolff M20 form — cost = mean|ΔQ| ×
(number of possible lines) — is what breaks that degeneracy.

**Indexing fixes the lattice, not a basis for it**, and re-embedding a motif into the wrong basis
yields structures that are geometrically valid and completely wrong. Monoclinic (a, c) is defined
up to a unimodular transformation — handled analytically by Gauss reduction, which took
baddeleyite from 27.6 % to **0.006 %** with cell volume preserved. Orthorhombic axis *labels* are
not determined by the lattice at all (Pnnm vs Pmnn is a labelling), so all six permutations are
scored by pattern fit; the choice is decisive, not marginal — marcasite's correct permutation
scores 0.0396 against 1.2971 for the runner-up.

## 5. The pipeline

```
1.  INDEX         cell from peak positions, given the space group      [0.003–0.019 %]
1b. STANDARDISE   Gauss reduction (monoclinic); setting by fit (orthorhombic)
2.  PROPOSE       CrystalFormer, conditioned on composition + space group
3.  MLFF RELAX    coordinates only, CELL HELD FIXED
4.  RANK          EMD + non-negative Chebyshev background, order 4–6
5.  REFINE        Wyckoff-respecting DE on the top candidate, in the indexed cell
```

**Stage 2 — the prior, and what it is worth.** Space-group conditioning is free and
transformative: baddeleyite's hit rate rises from 0.14 % to 9.33 %, a 67× gain, and conditioned
samples are better than merely filtered ones. Against quasi-random Wyckoff enumeration given the
same cell and space group, the prior plus MLFF gives the highest hit rate on 6 of 7 targets
(87–94 % against 42–79 %). Raw enrichment climbs steeply with dimension — 2.5× at one free
coordinate to unbounded at nine — but relaxation flattens it to a roughly constant 1.2–2.5×. So
the prior's value is real but is an efficiency and reliability win, not an enabler: quasi-random
enumeration plus a force field is a viable fallback everywhere tested.

**Stage 3 — relaxation, coordinates only.** Improves the top-1 rms by 44–89 % where there is room.
The cell is held fixed for the reason in §4.

**Stage 5 — refinement within Wyckoff freedom.** Every target improves; quartz by **1800×**
(0.1818 → 0.0001), which is what takes the pipeline from 6/7 to 7/7.

Two implementation points, because the generic approach fails:

- **Degrees of freedom must be derived, not assumed.** A site at **r** has site-symmetry group S;
  allowed displacements are those invariant under S, i.e. the column space of
  `P = (1/|S|)·Σ R_op`, whose rank is the site's dof. Derived this way the seven targets give
  **1, 1, 1, 2, 4, 7, 9** — matching the International Tables parameterisation exactly, from each
  structure alone with nothing hardcoded.
- **Orbits must be generated explicitly.** `Structure.from_spacegroup` recognises a special
  position only in its canonical form, while `SpacegroupAnalyzer` returns an arbitrary orbit
  member — so quartz's Si (3*a*, canonically `(x, 0, ⅓)`) gets expanded to the 6-fold orbit.
  Applying the space-group operations directly and de-duplicating is representative-independent.

Refinement helps when the cell is accurate and hurts when it is not: against a deliberately
mis-set 0.3 % cell it degrades baddeleyite, because the reward's optimum sits away from the truth
and nine free parameters let the optimiser chase it. At an indexed 0.006 % cell the same
refinement improves it 8×. Every stage inherits the cell's quality.

## 6. Is q(X) necessary?

**The finished pipeline contains no q(X)** — no policy optimisation, no KL term, no τ. The prior
is used purely as a sampler. What made the problem tractable was indexing the cell (§4),
conditioning on the space group (§5), and refining within Wyckoff freedom (§5) — each replacing
something q was supposed to do.

**τ cannot be swept without building q.** With q = p the KL term is identically zero and τ
multiplies nothing. τ is a hyperparameter of the RL loop, not a separable measurement, so the
challenge's milestone 3 is a from-scratch implementation of q rather than an addition to this
pipeline.

**Where the pipeline already sits.** Best-of-N with `argmax r` approaches the **τ → 0** limit of
the variational problem, reached by brute-force selection instead of learning; τ → ∞ (q → p)
ignores the data entirely. A sweep could only ask whether some intermediate τ beats that
endpoint — and the endpoint now returns rms ≤ 0.0015.

**What q could still uniquely do.** Refinement moves *continuous* coordinates inside a fixed
Wyckoff assignment. It cannot change the *discrete* structure — space group, which sites are
occupied, their multiplicities — which comes from CrystalFormer's first tokens (g, W, A). Where
the prior proposes the wrong discrete skeleton, nothing downstream recovers, and shifting that
distribution is the one thing only RL can do.

**Where finite τ might help: experimental data.** On real patterns it is the *reward* that
degrades — background, texture, preferred orientation, broadening — while the prior's chemistry
is unchanged. `argmax r` has no protection against fitting noise; finite τ hedges by staying
tethered to p. That is an argument for trusting the prior *more* when the data is less
trustworthy, not for RL correcting a misleading prior — and `supp(q*) ⊆ supp(p)` bounds it either
way. A cheaper approximation (top-k by reward, select by prior probability) captures much of the
same behaviour without PPO.

**Verdict.** On everything measured, the generative prior is *essential* and the variational
machinery around it is *unnecessary*. This is a negative result about the challenge's stated
hypothesis, reported with its scope attached.

## 7. Limits and open questions

**Hard ceiling.** CrystalFormer's `n_max` is 21 atoms per cell; corundum Al₂O₃ needs 30 and is
not representable at all. No amount of sampling or RL removes this.

**Untested regimes**, either of the first two of which could overturn §6:

1. **Implement q(X) and sweep τ** — milestone 3, and the only way the §6 verdict becomes a
   measured result rather than an inference. To be meaningful it needs a target this pipeline
   fails on; finding one is a precondition, since beating rms ≤ 0.0015 is not a real bar.
2. **How often is the discrete proposal wrong?** Count how often the space-group-conditioned pool
   contains the correct Wyckoff multiset. Cheap, and it isolates the one failure mode refinement
   structurally cannot repair.
3. **Experimental patterns.** Everything here is simulated; the literature reports a large
   simulated → experimental gap (67 % → 42 % on RRUFF).
4. **Full auto-indexing.** Ours is given the space group. Determining the crystal system from the
   pattern alone is the harder problem, and the IUCr literature reports unit-cell determination as
   a common hard failure.
5. **Proper Rietveld at stage 5.** The current refinement optimises the ranking metric; a
   refinement against the data with counting statistics is the principled version.
6. **Head-to-head benchmark** against arXiv:2605.24594 (94–100 % most systems, 60 % monoclinic).
   Without it, "better" is unsupported.
7. **Correlated and magnetic systems.** CuO defeats both priors independently — thin generative
   coverage (94 usable candidates against ~1800 elsewhere) and a 19.3 % force-field cell error.
   These need different fixes.

## 8. Reproducing

```bash
# sample the prior, space-group conditioned (~52 s on GPU)
cd ~/code/CrystalFormer && python main.py --optimizer none \
  --restore_path weights/epoch_046000.pkl --spacegroup 14 \
  --num_samples 2000 --batchsize 500 --formula ZrO2 --save_path samples_SG/

# solve, end to end
.venv/bin/python tracks/other/solutions/ForwardXRD/solve_pattern.py \
  --target baddeleyite --index real

# component checks
.venv/bin/python tracks/other/solutions/ForwardXRD/index_pattern.py    # indexing accuracy
.venv/bin/python tracks/other/solutions/ForwardXRD/wyckoff_refine.py   # derived dof
.venv/bin/python tracks/other/solutions/ForwardXRD/emd_nnls.py         # reward validation
```

| File | Role |

| `solve_pattern.py` | End-to-end solver, stages 1–5 |
| `index_pattern.py` | Symmetry-constrained indexing + setting standardisation (§4) |
| `wyckoff_refine.py` | Site-symmetry-derived refinement (§5) |
| `mace_relax.py` | MLFF relaxation; runs in a separate venv (torch's CUDA wheels clash with jax's) |

| `xrd_reward.py`, `emd_metric.py`, `emd_nnls.py`, `background_model.py` | The reward (§3) |
