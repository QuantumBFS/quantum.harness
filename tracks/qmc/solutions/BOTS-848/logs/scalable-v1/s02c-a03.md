## Contract

This attempt runs the exact one-layer strict-LLL Operator-NQS route at
`N=6, 2Q=15`.  The ground sector uses one `L=0` head; all five magnetic
components share one reduced `L=2` head.  The exact scalar action uses ranks
`2,3,4`; the neural trunk width is `64`.  Training is frozen to seeds
`848/1848/2848`, six independent sector batches of `512`, eight chains,
`1024` initial burn-in sweeps, Adam for exactly `2048` updates, checkpoint
interval `128`, and final-update-only selection.

The protocol SHA-256 is
`716383e208a186c338b1f2b8a15257b7708c176cc90811d24b1930e477f33f95`.
No ED oracle is imported, opened, or exposed.  There is no early-stop,
shortened-update, uniform-sampling, JK1/JKk, GMP, coefficient-only, or
partial-result path.

The Windows A03 checkout rewrites the otherwise unchanged protocol JSON to
uniform CRLF and therefore gives a checkout-byte hash of `63334c...`; Git
correctly reports no semantic/content diff because its text normalization
treats the files as equal.  The A02 frozen protocol file retains the exact
mixed-EOL bytes whose hash is `716383...`.  Production packaging explicitly
overlays those frozen bytes after `git archive`, then verifies the resulting
remote file before launch.  This preserves the ratified byte hash rather than
silently accepting a platform-dependent checkout hash.

## Production boundary

The first frozen production seed is also the one-real-update admission.  The
other two seeds may be submitted only after that job is `RUNNING`, its hash
banner is correct, startup stderr contains no actual error, and its
`training.jsonl` contains one complete six-sector update.  Once submitted,
jobs are not cancelled by the agent without explicit user instruction.

An incomplete JSONL, an intermediate checkpoint, a scheduler timeout, or a
manually stopped job is not a Challenge result.  Only update `2048` from the
frozen final checkpoint is eligible for selection.
