## A03.2 implementation

`train.py` implements the reduced objective exactly for the two `M=0`
sectors:

```text
E_ground + E_excited_m0
+ 0.25 * mean_l2_ground**2
+ 0.25 * (mean_l2_excited_m0 - 6.0)**2
+ 0.05 * variance_l2_excited_m0
```

Every energy and L2 value is evaluated through the reviewed sparse
`local_energy` and `local_l2` log-amplitude estimators.  The production CLI
reads the frozen protocol and fixes `batch_size_per_sector=512`; it does not
expose a batch, width, layer, checkpoint-selection, oracle, or early-stop
override.  Tiny zero-operator settings exist only as injected unit fixtures.

For each update the trainer creates a new logpsi memo for each sector.  It
caches only configurations reached by the current sampled sparse rows, never
enumerates support, and discards the memo before the next parameter update.
Analytic complex scores feed the real-parameter VMC covariance.  Gradients are
globally clipped and updated with the frozen Adam hyperparameters.

Progress is deterministic JSONL with one row per update.  Checkpoints use a
stable, timestamp-free NPZ encoding and `fsync` plus `os.replace`.  The normal
interval remains 128, while the final update always goes through the same
atomic path; therefore the 16-update A03 smoke records
`selected_update=16` even though 16 is not an interval boundary.  Existing
run artifacts are not silently overwritten.

`--n8-smoke` and the no-mode full schedule raise clear feature-state errors
until A05 installs the tower and adapter.  A03 cannot silently substitute a
two-state objective for either later mode.
