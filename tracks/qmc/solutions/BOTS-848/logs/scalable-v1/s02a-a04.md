## A04.1 minimal implementation

`LadderTower.from_m0` constructs a read-only mapping of `M=-2..2` components
from the single excited `M=0` logpsi and analytic-score callbacks.  Each
derived evaluation validates fixed `N` and fixed `M`, applies the inverse
sparse ladder neighbors for only the requested determinant, and recursively
evaluates its parent.  It does not enumerate a production support.

Finite parent phases are folded into sparse coefficients, with exact axial
phases preserved, before the existing bounded log-neighbor reducer performs
the shifted complex sum.  The analytic spin-2 ladder coefficient is subtracted
from the resulting log magnitude.  Exact cancellation returns
`complex(-inf, 0)` without a wavefunction ratio or intermediate amplitude
division.

For a nonzero derived amplitude, normalized complex term weights divide each
shifted sparse contribution by the same bounded total.  The analytic score is
exactly the weighted sum of parent scores.  Parameter widths and finite values
are checked before returning.  Zero-amplitude scores and invalid targets,
states, sectors, directions, or ladder boundaries fail closed.

No sampler, Markov proposal, diagnostics, adapter, factory, N=8 path, common
evaluator, ED/oracle import, dense matrix, projector, or Ritz operation was
added.

### Minimal implementation

`FixedMMetropolisSampler` precomputes every unordered orbital pair and groups
pairs by identical orbital-index sum, which is identical to fixed pair
magnetic quantum number.  Each step chooses a group and two distinct pairs
without consulting the current determinant.  A fully occupied pair swaps with
a fully empty pair; every other choice is a self-loop.  Consequently each
nontrivial proposal and reverse have exactly the same probability.

Acceptance returns one before subtracting logs when the proposed real log
amplitude is no smaller, otherwise evaluates only the non-positive expression
`exp(2 * (new.real - old.real))`.  Proposed exact zeros reject with probability
one; current exact zeros and every other non-finite value fail closed.  Initial
states come from the fixed-`N/M` feasibility sampler with bounded nonzero
retries.  Burn-in proposals/accepted moves and returned-sample
proposals/accepted moves are recorded separately; no burn-in configuration is
returned as a sample.

`evaluate_tower_diagnostics` returns a read-only mapping with exactly four
fields.  The LLL and particle-swap construction residuals are exact zeros.  The
ladder residual evaluates inverse sparse ladder actions only at requested
states.  Finite rotations build spin-`Q` and spin-two one-body matrices and
Slater determinant minors.  Explicit tiny supports are accepted only for
fixtures with at most four particles; the production branch obtains seeded
fixed-`M` samples and uses importance estimates, without calling a support
enumerator or allocating a physical determinant basis.
