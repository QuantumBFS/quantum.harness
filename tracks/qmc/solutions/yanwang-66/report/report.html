Challenge 66：什么时候重装原子真正有帮助？

https://github.com/QuantumBFS/quantum.harness/issues/66

在 1.92 亿次已验收 cell-shots 中，动态重装产生了 502 个暂定正面、0 个有害的 FDR 分类；独立种子确认的 32/32 个比较通过精度门，严格停止规则则保留了科学结论的边界。

Challenge

原子丢失不是普通 Pauli 错误：载体离开阵列后，空位会跨纠错轮累积。重装可以恢复硬件占用，却不能恢复原子丢失前的未知量子态。

本研究比较四类策略：不重装、检测后立即重装、每隔 R 轮周期重装，以及缺失比例超过阈值后集中重装。问题不是“能不能补原子”，而是重装带来的占用恢复能否在逻辑层面超过等待、复位错误和失败重试的代价。

Significance

中性原子平台天然面对 loss，而表面码能够利用“已知在哪里丢失”的擦除信息。一个可复现的策略区域基准可以直接连接器件调度、容错架构和未来 learned decoder 的数据接口。

Approach

所有策略在同一 shot 上共享逐轮、逐位置、逐事件类型的外生随机数；差值因此主要反映策略决策，而不是两批独立样本的运气。

Finite-size paired Monte Carlo · deterministic replay
Method
Round-level circuit Monte Carlo + erasure-aware MWPM
Tools

Randomness

Highlight

这项工作的价值不只是一组 Monte Carlo 数字，而是把动态硬件修复变成一个可因果比较、可恢复运行、可独立审计的量子纠错基准。

What's innovative

策略与噪声解耦。 Counter-addressed common random numbers 让所有策略经历相同外生事件，避免“某策略碰巧抽到更容易样本”的伪改进。

动态擦除进入解码图。 缺失掩码不是只保存到文件，而是按每轮已知 loss history 构造 super-stabilizer / erasure-aware matching graph。

失败也可审计。 Checkpoint、atomic publish、checksum manifest 和 fail-closed resume 保证超算超时不会把半成品混入科学结果。

Significance of output

502 个 helpful 与 0 个 harmful 暂定分类说明主动重装不是一个边缘效应，值得继续定位它的适用参数区间。独立 confirmation 的 32/32 精度成功又表明，当前主要缺口是保守事件计数，而不是估计完全不稳定。

Broader impact

版本化的 syndrome + missing/reload history + metadata 输入接口可以直接服务未来的 MWPM 改进或 learned decoder，同时保持 logical label 隔离。它也提供了连接中性原子 telemetry、部分可观测控制和相关 loss 模型的基础。

Claim boundary 本结果支持“动态重装在部分参数区间有潜在收益”，不支持“某一策略在所有噪声下普遍最优”，也不把 d=3,5 的有限尺寸现象称为渐近阈值。
