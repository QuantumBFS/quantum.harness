The input is downloaded rather than committed.  `scripts/fetch_public_data.py`
checks both size and SHA-256 before accepting it.

The public table contains run-level estimates and marginal errors.  It does
not contain synchronized bin means, joint jackknife replicas, or the full
cross-observable covariance required for a definitive joint likelihood.
