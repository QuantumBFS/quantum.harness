横场伊辛模型数值方法与几何相位研究成果报告

日期：2026-07-30

摘要

本报告总结关于横场伊辛模型的两项数值研究成果。

第一项工作为主要内容，研究随机级数展开方法中三种算符更新算法（ cluster 算法、 loop 算法与 local worldline line 算法）的实现与性能比较。原始研究目标为检验三角晶格与蜂窝晶格铁磁横场伊辛模型的零温临界横场比值是否等于 \(\sqrt{5}\) 。受限于计算资源，在目标精度要求下未能完成最终比值判定。核心成果为基于 C++17 统一实现的算符更新算法框架、有限温度精确对角化交叉检验集合、自相关与单扫墙钟时间基准数据，以及基于晶格着色的空间并行方案。

第二项工作为附带内容，研究二维方晶格横场伊辛模型在 Kolodrubetz 全局旋转参数化下的基态 Berry 相与 Berry 曲率密度。通过无矩阵复 Lanczos 精确对角化与 Resolvent 共轭梯度算法将计算规模扩展至 \(L=5\) （ 25 个格点），推导并验证了 Berry 曲率与横场磁化率的解析恒等式 \(F_{\theta\Omega} = -\frac{1}{2} \chi_x\) ，证明了 Rydberg 激光相位参数化下 Berry 曲率严格为零的物理结论，拟合反比矩复现了动力学指数 \(z=0.9999 \approx 1\) ，并完成了 \(D=2\) 键维下无限张量网络（ iPEPS ）基态能量的精确对比。

所有源代码、计算参数、测试脚本与数据均已归档保存，具备可审查与可复现条件。

1. Challenge 148：随机级数展开更新算法比较与临界场研究

1.1 研究对象与主要进展

研究体系为铁磁横场伊辛模型：

\[ H = -J \sum_{\langle i,j \rangle} \sigma_i^z \sigma_j^z - \Gamma \sum_i \sigma_i^x \]

其中 \(J=1\) ，横场参数 \(\Gamma = h\) 。原始研究目标为判定三角晶格与蜂窝晶格的零温临界横场比值：

\[ R = \frac{h_c^{\triangle}}{h_c^{\mathrm{hex}}} \stackrel{?}{=} \sqrt{5} \]

目标精度要求 \(\sigma_R \le 1.2 \times 10^{-5}\) 。在现有计算资源条件下，有限尺寸标度的独立采样块不足，导致外推误差无法达到预设精度门限，未能在有限时间内完成最终的比值判定。

在研究过程中完成的工作与成果包括： 1. 基于 C++17 实现了三种统一数据结构的随机级数展开（ SSE ）更新算法： cluster 算法、 loop 算法与 line 算法。 2. 建立全谱精确对角化（ ED ）验证集合，对三种算法在 \(\beta=2\) 条件下的能量与磁化强度等观测量进行了交叉检验。 3. 定量测量了各算法在不同晶格与观测量下的自相关时间与单扫墙钟时间，计算了有效样本率。 4. 在 Julia 语言原型中实现了基于晶格着色的 line 更新空间并行方案，测试了颜色核的强扩展性能。

1.2 三种更新算法实现

随机级数展开方法将量子配分函数展开为高温算符序列。三种更新算法共享晶格构造、算符存储数组、对角更新例程与测量模块：

  • cluster 算法：通过键算符将相连的世界线段连接为簇，并进行整体随机翻转。该算法能够有效消除磁化强度的长波自相关，但仅适用于纵向场 \(B=0\) 的情形。
  • loop 算法：基于 merge-unmerge 转移规则构造闭合环路翻转。该算法具备处理非零纵向场 \(B \neq 0\) 的能力，但在零纵向场条件下的单扫计算开销较高。
  • line 算法：逐格点构造局部世界线段，并采用 heat-bath 概率进行翻转：

\[ P_{\mathrm{accept}} = \frac{R}{1+R} \]

针对晶格几何，蜂窝晶格可划分为 2 种颜色，三角晶格在尺寸为 3 的倍数时可按如下公式划分为 3 种颜色：

\[ c(x,y) = (x+2y) \bmod 3 \]

同色格点之间不共享相互作用键，这为线段翻转提供了空间并行条件。

1.3 精确对角化交叉检验

为保证算法实现的正确性，使用全谱精确对角化计算 \(\beta=2\) 时的热力学平均值。三角晶格采用 \(3\times 2\) 周期簇（ 6 格点），蜂窝晶格采用 \(2\times 2\) 原胞（ 8 格点）。三种更新算法均运行 5000 扫热化与 20000 扫测量。

比较的可观测量包括能量密度 \(E/N\) 、横场磁化强度 \(m_x\) 与磁化强度二次方 \(m^2\) 。测试结果显示， 18 项比较的绝对标准化偏差均小于 4 倍标准误差门限（最大偏差为 1.45 ），排除了算法实现中的基本错误。

1.4 自相关时间与计算效率

在三角晶格（ \(L=12, \beta=24, h=4.76811\) ）与蜂窝晶格（ \(N=128, \beta=16, h=2.13250\) ）上开展了性能测定。计算指标采用每秒有效样本数（ ESS/s ）：

\[ \mathrm{ESS/s} = \frac{1}{2\tau_{\mathrm{int}} t_{\mathrm{sweep}}} \]

其中 \(\tau_{\mathrm{int}}\) 为自相关时间，\(t_{\mathrm{sweep}}\) 为单扫墙钟时间。

1.5 晶格着色并行测试

在 Julia 原型代码中实现了 line 更新的颜色类并行。测试表明， 8 线程下颜色更新核在三角晶格获得 4.90 倍加速，在蜂窝晶格获得 2.51 倍加速。但受限于对角更新与测量模块的串行执行，完整单扫加速比降低至 1.66 倍（三角）与 1.20 倍（蜂窝）。

1.6 未完成原因与后续优化空间

临界场比值判定未完成的原因在于：有限尺寸标度模拟中独立采样块数量不足，导致临界外推结果的统计误差偏大，无法达到判定比值所需的精度门限。

后续优化空间包括： 1. 在 C++ 框架中实现对角更新与格点列表构造的并行化，降低串行部分比例。 2. 结合 cluster 算法在磁化强度更新上的优势与 line 算法在能量更新上的高效性，设计混合更新策略。 3. 将 loop 算法扩展应用于非零纵向场 \(B \neq 0\) 的相图计算。

2. Challenge 73：二维方晶格横场伊辛模型的 Berry 相与曲率

2.1 问题描述与计算方法

研究二维方晶格横场伊辛模型在 Kolodrubetz 全局旋转参数化下的基态 Berry 相与 Berry 曲率密度：

\[ H(\theta, \Omega) = R_x(\theta) H_0(\Omega) R_x^\dagger(\theta), \quad R_x(\theta) = \exp\left(-\frac{i\theta}{2} \sum_i X_i\right) \]

其中：

\[ H_0(\Omega) = -J \sum_{\langle i,j \rangle} Z_i Z_j - \Omega \sum_i X_i \]

数值计算采用了两种互补路线：其一是 Fukui-Hatsugai-Suzuki (FHS) 离散 Wilson 回路公式；其二是基于无矩阵实对称 Lanczos 与投影共轭梯度 (Resolvent CG) 的求解路线。 Resolvent 路线避免了参数网格离散化误差，并将计算规模扩展至 \(L=5\) (25 个格点， Hilbert 空间维数 \(1.68 \times 10^7\) )。

2.3 响应函数恒等式与物理理解

通过参数化求导推导得出 Berry 曲率与横场磁化率的二阶响应恒等式：

\[ F_{\theta\Omega} = \frac{1}{2} \frac{\partial^2 E_0}{\partial \Omega^2} = -\frac{1}{2} \chi_x \]

其中 \(\chi_x\) 为系统的横场磁化率。

由于横场磁化率作为二阶响应函数恒满足非负条件 \(\chi_x \ge 0\) ，因此恒有 \(F_{\theta\Omega} \le 0\) 。这一解析恒等式解释了数值计算中 Berry 曲率恒为负值的必然性。

通过 Resolvent 路线计算谱函数的反比矩 \(M_1 = -F_{\theta\Omega}\) 与 \(M_2 = \chi_F\) ，平均响应能隙 \(M_1/M_2\) 在 \(L=2\) 至 \(L=5\) 范围内拟合得到动力学指数 \(z = 0.9999\) ，精确复现了 \((2+1)\mathrm{D}\) 伊辛普适类的 \(z=1\) 理论预测。

2.4 Rydberg 参数化严格结果

研究了第二种参数化方式（ Rydberg 激光相位参数化）：

\[ H^{\mathrm{Ryd}}(\phi, \Omega) = -J \sum_{\langle i,j \rangle} Z_i Z_j - \Omega \sum_i (\cos\phi \, X_i + \sin\phi \, Y_i) \]

绕 \(Z\) 轴的整体旋转操作与 Ising 键项对易。推导证明该参数化下的 Berry 联络分量相互独立，因此导出：

\[ F_{\phi\Omega}^{\mathrm{Ryd}} \equiv 0 \]

FHS Wilson 回路数值计算在 1D 链与 2D 方晶格上测得的 Berry 相相位在数值精度范围内（小于 \(10^{-13}\) ）严格为零，与解析证明完全吻合。这表明量子态流形的几何曲率依赖于参数化路径的选择。

2.5 热力学极限外推与张量网络验证

在顺磁相区间利用 \(1/L\) 线性标度将 Berry 曲率密度外推至热力学极限 \(L \to \infty\) 。外推结果显示：在 \(\Omega=4.0\) 时外推值为 \(-0.0110(11)\) ，在 \(\Omega=5.0\) 时为 \(-0.0020(1)\) 。随着横场增大，曲率趋于零，与完全极化基态的几何性质一致。

图 5：顺磁相区域 Berry 曲率密度的 \(1/L\) 线性有限尺寸外推。

在无限张量网络（ iPEPS ）方法中，使用 PEPSKit.jl 在 \(D=2\) 键维下计算得到基态能量密度为 \(E/N = -2.12566\) ，与 \(L=4\) 精确对角化数值 \(-2.126\) 相比，相对偏差仅为 0.01% 。环境维度在 \(\chi=4\) 至 \(\chi=8\) 之间收敛良好（能量变化小于 \(10^{-7}\) ）。更高键维 \(D \ge 3\) 的计算受限于即时编译超时。

2.6 成果不足与后续方向

Challenge 73 完成了 Berry 相、 Berry 曲率密度、响应函数恒等式、动力学指数验证与 Rydberg 严格零曲率的求解。不足之处在于：未实现慢演化下的非绝热有限速率修正，未包含非零纵向场 \(\Delta \neq 0\) 的完整二维参数扫描，且张量网络高键维计算尚未完成。

后续优化方向包括：利用响应函数恒等式直接计算更大尺寸系统的 Berry 曲率，在临界点附近加密采样，并实现基于时域演化的非绝热动力学修正。

3. 结论

本研究在横场伊辛模型的量子蒙特卡洛算法与基态几何相位两个方向取得了阶段性成果。在 Challenge 148 中，实现了三种随机级数展开更新算法，建立了精确对角化交叉检验与自相关性能基准，揭示了单扫墙钟时间与自相关时间在不同观测量下的竞争机制。在 Challenge 73 中，计算了二维方晶格基态 Berry 曲率密度，建立了 Berry 曲率与横场磁化率的解析恒等式，复现了 \(z=1\) 动力学指数，证明了 Rydberg 参数化下曲率严格为零的特性，并通过 iPEPS 张量网络验证了基态能量。

所有源代码、计算参数、测试脚本与输出数据均已保存在仓库指定目录下，具备可审查与可复现条件。
