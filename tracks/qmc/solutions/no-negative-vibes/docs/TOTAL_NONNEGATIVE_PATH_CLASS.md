# 全非负路径半群：严格结论与物理落地

更新时间：2026-07-28

## 结论先行

我们找到了一条不靠随机样本的恒正机制。若每个单粒子生成元都是实三对角矩阵

```text
A_l =
[ *  +  0  0 ]
[ +  *  +  0 ]
[ 0  +  *  + ]
[ 0  0  +  * ]
```

其中相邻上下对角元非负、主对角元任意，则

```text
B_l = exp(A_l)
D   = B_1 B_2 ... B_L
w   = det(I + D)
```

对任意矩阵维数、任意时间片数和任意参数强度都有

```text
w >= 1.
```

对普通 Hermitian 模型，上下对角元相等；定理其实还允许二者不同。一个固定的对角符号
规范变换也不改变结论，但每个时间片独立换规范会破坏它。

## 三步证明

### 1. 单片演化全非负

“全非负（totally nonnegative, TN）”指矩阵的每一个方形子式都非负。经典的全正微分
系统定理说明：实三对角生成元的相邻上下对角元非负时，`exp(t A)` 对所有 `t >= 0`
都是 TN；不可约且 `t>0` 时通常严格全正。

这不是我们发明的数学定理。可参考
[Margaliot and Sontag, 2018](https://arxiv.org/abs/1802.09590) 的教程，以及
[Fomin and Zelevinsky, 1999](https://arxiv.org/abs/math/9912128) 对全正矩阵判据和参数化
的综述。

### 2. 任意时间片乘积仍全非负

Cauchy--Binet 公式给出：两个 TN 矩阵的任意子式都是非负数之和，所以 TN 矩阵对乘法
封闭。因此

```text
D = exp(A_1) exp(A_2) ... exp(A_L)
```

仍然是 TN。

### 3. QMC 权重是主子式之和

对任意方阵 `D`，

```text
det(I + D) = sum_{S subset {1,...,N}} det D[S,S].
```

TN 矩阵的全部主子式非负，而空集项等于 `1`，所以 `det(I+D) >= 1`。这一步把经典
全非负理论直接接到了有限温辅助场 QMC 的逐构型行列式权重。

## 最小物理模型 1：掺杂的开放 Hubbard 链

考虑开边界最近邻 Hubbard 链

```text
H = -t sum_(i,sigma) (c^dagger_(i,sigma)c_(i+1,sigma) + h.c.)
    -mu sum_(i,sigma) n_(i,sigma)
    +U sum_i (n_(i,up)-1/2)(n_(i,down)-1/2),    U >= 0.
```

Hirsch 离散 HS 恒等式为

```text
exp[-dt U (n_up-1/2)(n_down-1/2)]
  = C sum_(s=+-1) exp[lambda s (n_up-n_down)],

cosh(lambda) = exp(dt U/2),
C = exp(-dt U/4)/2 > 0.
```

用对称 Trotter 分解，一片的两个自旋矩阵是

```text
B_l^(sigma) = exp(K/2) exp[sigma lambda diag(s_l)] exp(K/2).
```

`K` 是开放路径的三对角 Metzler 生成元；中间因子是正对角矩阵。三者都 TN，因此每个
自旋的 `det(I+D_sigma) >= 1`，HS 标量 `C` 也为正。化学势只改变主对角元，所以结论
不要求半填充。

`oracle/path_hs.py` 给出了可执行的最小实现。自动测试穷举了三站点、三时间片的全部
`2^9=512` 个 HS 构型；在测试参数下两个单自旋行列式的最小值都是
`1.294424321334...`，总权重始终为正。

开放最近邻一维 Hubbard 模型无符号本身已有使用先例；例如
[Phys. Rev. Research 4, L042015 的补充材料](https://journals.aps.org/prresearch/supplemental/10.1103/PhysRevResearch.4.L042015/Supplementary_Material.pdf)
明确把它作为无符号基准。因此这部分是物理基线和证明语言，不作为新模型认领。

## 最小物理模型 2：单 flavor 排斥 `t-V` 开放链

更能体现“单个行列式恒正”的例子是

```text
H = -t sum_i (c_i^dagger c_(i+1) + h.c.) - mu sum_i n_i
    +V sum_i (n_i-1/2)(n_(i+1)-1/2),    V >= 0.
```

每条键使用

```text
exp[-dt V (n_i-1/2)(n_j-1/2)]
  = C sum_(s=+-1) exp[lambda s (n_i-n_j)].
```

所有键场只产生实对角势，所以每片仍是“TN 动能因子 × 正对角因子 × TN 动能因子”。
于是任意化学势下，单 flavor 权重也逐构型严格为正。测试穷举了四站点、四时间片的
`2^12=4096` 个键场构型。

一维开边界可通过 Jordan--Wigner 消除交换符号，所以“这个物理模型最终应当无符号”
并不意外；目前值得核实的是：上述密度通道 DQMC 的 TN 证明及其任意化学势表述，在文献
中是否已经被明确写出。

## 边界在哪里

本轮计算给出了很清楚的边界：

- 开放路径：严格证明安全；
- 同一个固定符号规范下的路径：与开放路径相似变换等价，安全；
- 每片独立改变符号规范：48,000 个样本中有 6,965 个负权；
- 四点环：397 个负权；
- 四点星形图：63 个负权；
- 四点完全图：101 个负权。

这与全正微分系统的生成元结构一致：在固定顶点顺序下，连续 TN 半群的局部生成元只允许
主对角和相邻上下对角方向。给开放路径增加一条弦、分支或闭合边，就离开了这条生成元锥。

## 新颖性判断

目前最稳妥的表述是：

- **严格数学机制成立**，不是数值猜想；
- **全非负矩阵半群是经典数学**；
- **开放一维 Hubbard 无符号是已知物理事实**；
- **把 TN 半群直接写成 `det(I+D)` 的逐构型 QMC 充分条件，并系统展示其最大路径边界，
  可能是有用的新表述或推广，但尚不能声称首创**；
- 非对称三对角生成元、任意 TN 时间片和单 flavor `t-V` 的任意化学势版本，是下一轮
  文献排重的重点。

若要形成真正新的物理结果，下一步不能只重复一维开放链，而要从 TN 的平面网络/
双对角分解出发，找到一个不明显约化为普通 Jordan--Wigner 开链、且有实际 HS 来源的
模型；或者找到比 TN 更大的、对乘法封闭且全部主子式仍非负的半群。
