# 任意小夹角也会产生负权：一个两层解析反例

## 结论

不存在只依赖夹角的“恒正小角区”。只用 4 个 Majorana 和 2 个时间层，就能对每个

```text
0 < theta < pi
```

构造两个共享同一 `J1`、但收缩方向 `J2` 相差 `theta` 的合法正锥生成元，使物理 Fock
权重精确等于

```text
p(theta, q) = -4 sin(theta) sinh(q)^2 < 0,    q > 0.
```

因此，无论 `theta` 多小，都存在负权。此前随机扫描在 `theta=0.05–0.3` 没有命中，是抽样
分布漏掉了锥边界上的精细构造，不是这个区域恒正。

## 不用群论理解这个结果

把每个已知 Majorana 正锥想成一个无限延伸的漏斗。两个漏斗的轴只差一个很小的角度时，
大部分普通点确实仍然表现相近，所以随机抽样很难看到问题。

但是漏斗有一条很尖的边界。在这条边界上，可以先把零角度权重调到恰好为零。此时再小的
转动都会把它推到零的负侧。关键不是“大角度造成大破坏”，而是：

```text
零权边界 + 任意非零转动 = 可以出现负权
```

这也解释了为什么负例在小角随机扫描中很稀少。

## 构造

4-Majorana 正锥生成元可写成

```text
A = [[ B,   i C ],
     [-i C^T, B* ]],
```

其中 `B` 是 `2 x 2` 复反对称矩阵，`C` 是半正定 Hermitian 矩阵。取任意 `q>0`，

```text
C = q [[ 1,  i],
       [-i,  1]].
```

`C` 的两个本征值是 `0` 和 `2q`，所以它恰好位于半正定锥的秩一边界。两个时间层分别取

```text
B1_12 = pi - i q,
B2_12 =      i q.
```

第一层使用原来的 `J2`；第二层先按同样的块公式构造，再用与 `J1` 对易的
`O(theta)` 旋转，使其属于 `J2(theta)=O(theta)J2O(theta)^T` 的正锥。代码实现是
`oracle.majorana.small_angle_negative_pair`。

## 两个 2 x 2 块就能算完

4 维 Fock 空间分成偶、奇两个宇称块。上述选择使偶宇称块的两层贡献为

```text
p_even = -2.
```

令

```text
c = cos(theta/2),  s = sin(theta/2).
```

奇宇称块的两个指数矩阵都是下三角矩阵；旋转第二层后直接相乘可得

```text
p_odd = 2 - 8 c s sinh(q)^2
      = 2 - 4 sin(theta) sinh(q)^2.
```

相加后常数 `-2` 与 `+2` 抵消：

```text
p = p_even + p_odd
  = -4 sin(theta) sinh(q)^2.
```

所以 `theta=0` 时权重恰好为零，而任意 `0<theta<pi` 都严格为负。这里不需要统计推断，
也不存在浮点符号不确定性。

机器可读公式保存在
[majorana_trace_certificates.json](../fixtures/majorana_trace_certificates.json)，SymPy 测试会
验证解析化简；生产 Fock oracle 还会在从 `1e-6` 到 `3` 弧度的多个角度重放该反例。

## 它关闭了什么、还留下什么

这个结果关闭了：

1. 两个共享 `J1` 的完整 Majorana 正锥在足够小夹角下可以任意混用；
2. 存在仅由 `theta < theta_c` 保证的统一无符号区；
3. 继续用同一种随机分布堆叠小角样本可能找到新恒正类。

它没有排除更严格的联合条件。例如，同时限制：

- `C` 离秩亏边界至少有固定距离；
- 生成元范数和时间层数有统一上界；
- 两个锥只取某个物理 Hamiltonian/HS 分解真正能到达的子集；
- 所有时间层共享一个更强的公共收缩度量。

这些限制可能给出有限系统上的定量安全半径，但那将是“角度 + 范数 + 离边界距离”的条件，
不是新的无条件完整锥。

## 对项目方向的影响

“旋转后完整双锥的并集”已经被解析反例彻底排除。后续值得做的是：

1. 寻找两个已知锥的受限交集或共同收缩度量，而不是混用完整并集；
2. 从具体 Hamiltonian 和 Hubbard--Stratonovich 分解反推可达子集，检查它是否自动避开
   上述秩一零权边界；
3. 若需要工程性结果，推导权重对角度、范数和离边界距离的联合下界。
