# 精确证书与测试锚点

这些证书是 oracle 必须通过的回归基线，不是新的研究结论。机器可读的唯一数据源是
[exact_certificates.json](../fixtures/exact_certificates.json)；本页解释它们为什么成立。

## 统一约定

对单粒子演化矩阵 `D`，测试权重为

```text
w(D) = det(I + D).
```

JSON 中所有数字都保存为 SymPy 可解析的有理或代数表达式字符串。精确测试必须先用符号运算
验证，再把同一案例交给浮点 oracle；不能先转成浮点数再声称得到“精确证书”。

## O(1,1) 的正、负、零控制

取 `eta = diag(1,-1)`。下列三个矩阵都精确满足 `D^T eta D = eta`：

```text
D_++ = (1/3) [[ 5,  4],       w(D_++) =  16/3
              [ 4,  5]]

D_-- = (1/3) [[-5, -4],       w(D_--) =  -4/3
              [-4, -5]]

D_+- =       [[ 1,  0],       w(D_+-) =   0
              [ 0, -1]]
```

它们分别锚定 split-orthogonal 定理的正分支、负分支和混合分支。任何把三者都报告为
“非负”的实现，都混淆了群的连通分支或错误处理了零点。

## Sp(2,R) 的四剪切负权证书

定义

```text
U(x) = [[1,x],[0,1]],    L(y) = [[1,0],[y,1]].
```

每个因子都是一个平方为零的 `sp(2,R)` 生成元的指数。精确相乘得到

```text
U(-3) L(1) U(-3/2) L(2) = diag(-2,-1/2),
w = (-1)(1/2) = -1/2.
```

因此实辛群即使从合法指数因子生成，也不普遍无符号。直和单位阵后，
`Sp(2n,R)` 中的权重为 `-2^(2n-3)`，仍然为负。

## SU(1,1) 的有理负权证书

取

```text
D = (1/4) [[-5,-3],
           [-3,-5]].
```

它精确满足 `D^dagger eta D = eta` 和 `det(D)=1`，但

```text
det(I+D) = -1/2.
```

把它嵌入一个正、一个负方向，并在其余方向补单位阵，就得到任意 `p,q >= 1` 的
`SU(p,q)` 负权例，权重为 `-2^(p+q-3)`。

## 更高维与复相位锚点

其余六个案例补齐基线扫描中容易误判的结构：

| 案例 | 精确权重 | 用途 |
|---|---:|---|
| `SL(3,R)` 内嵌四剪切 | `-1` | 排除特殊线性群的普遍非负性 |
| `Sp(4,R)` 内嵌四剪切 | `-2` | 确认高维辛嵌入和辛形式约定 |
| `SU(2,1)` 内嵌 `SU(1,1)` | `-1` | 排除更高维伪特殊酉群 |
| `SU(3)` 中心元 | `-1` | 捕获随机扫描中较稀少的紧群负例 |
| `U(2)` 的 `diag(i,1)` | `2+2i` | 确认一般酉群权重不是实数 |
| `U(1,1)` 的 `diag(i,1)` | `2+2i` | 确认伪酉约束也不自动消除相位 |

`SU(3)` 中心元使用 `sqrt(3)` 和 `I`，所以它是精确代数证书，但不是有理证书。所有
嵌入剪切仍由幂零李代数生成元的指数构成。

## AZ Hermitian 时间片的深度三证书

AZ 扫描新增五组证书，覆盖六个失败类：

| 类 | 三个正定因子的精确权重 |
|---|---:|
| AI | `-36` |
| AIII | `-753344/133875` |
| CI | `-53744/7875` |
| A 与 D | `2816/27 + (77824/729) i` |
| C | `2816/27 - (77824/729) i` |

这里保存的因子是 `P_i = exp(A_i)`，不是浮点矩阵指数。测试精确验证每个 `P_i` Hermitian
正定，并验证相应的 TRS、PHS 或手征关系。正定主对数 `A_i=log(P_i)` 因而存在且满足相应
AZ 生成元约束。详细解释见 [AZ_TENFOLD_RESULTS.md](AZ_TENFOLD_RESULTS.md)。

## 两个旋转 split cones 的有理两层证书

新增证书取 `sin(theta)=4/5`、`cos(theta)=3/5`、`q=2`，把二维秩一幂零生成元嵌入四维。
两个时间片分别精确满足各自度量的

```text
A_i^T eta_i + eta_i A_i >= 0,
A_i^2 = 0,
exp(A_i) = I + A_i.
```

符号计算得到

```text
det[exp(A_1) exp(A_2)] = 1,
det[I + exp(A_1) exp(A_2)] = -624/25.
```

测试同时验证两个 cone 矩阵的全部精确特征值非负。它是一般公式
`16[1-q^2 sin^2(theta)]` 的有理锚点。

## Oracle 的最低通过条件

1. 精确层逐项验证结构关系、`det(D)` 和预期权重。
2. 双精度层正确给出 17 个 determinant 案例的正、负、零或复相位分类。
3. 零权案例不能被固定容差随意归入正数；结果要带数值不确定状态。
4. 因子乘积路径和直接输入最终矩阵的路径必须一致。
5. 未来增加的反例先进入 JSON，再进入自动测试，避免结论只留在聊天记录里。
