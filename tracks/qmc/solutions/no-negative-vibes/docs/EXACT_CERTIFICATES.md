# 精确证书与测试锚点

这些证书是 oracle 必须通过的回归基线，不是新的研究结论。机器可读的唯一数据源是
[exact_certificates.json](../fixtures/exact_certificates.json)；本页解释它们为什么成立。

## 统一约定

对单粒子演化矩阵 `D`，测试权重为

```text
w(D) = det(I + D).
```

JSON 中所有数字都保存为有理数字符串。精确测试必须先用有理/符号运算验证，再把同一案例交给
浮点 oracle；不能先转成浮点数再声称得到“精确证书”。

## O(1,1) 的正、负、零控制

取 `eta = diag(1,-1)`。下列三个矩阵都精确满足 `D^T eta D = eta`：

```text
D_++ = (1/3) [[ 5,  4],       w(D_++) =  16/3
              [ 4,  5]]

D_-- = (1/3) [[-5, -4],       w(D_--) =  -4/3
              [-4, -5]]

D_+- =       [[ 1,  0],       w(D_+-) =   0
              [ 0, -1]]
```

它们分别锚定 split-orthogonal 定理的正分支、负分支和混合分支。任何把三者都报告为
“非负”的实现，都混淆了群的连通分支或错误处理了零点。

## Sp(2,R) 的四剪切负权证书

定义

```text
U(x) = [[1,x],[0,1]],    L(y) = [[1,0],[y,1]].
```

每个因子都是一个平方为零的 `sp(2,R)` 生成元的指数。精确相乘得到

```text
U(-3) L(1) U(-3/2) L(2) = diag(-2,-1/2),
w = (-1)(1/2) = -1/2.
```

因此实辛群即使从合法指数因子生成，也不普遍无符号。直和单位阵后，
`Sp(2n,R)` 中的权重为 `-2^(2n-3)`，仍然为负。

## SU(1,1) 的有理负权证书

取

```text
D = (1/4) [[-5,-3],
           [-3,-5]].
```

它精确满足 `D^dagger eta D = eta` 和 `det(D)=1`，但

```text
det(I+D) = -1/2.
```

把它嵌入一个正、一个负方向，并在其余方向补单位阵，就得到任意 `p,q >= 1` 的
`SU(p,q)` 负权例，权重为 `-2^(p+q-3)`。

## Oracle 的最低通过条件

1. 精确层逐项验证结构关系、`det(D)` 和预期权重。
2. 双精度层正确给出五个案例的正、负、零分类。
3. 零权案例不能被固定容差随意归入正数；结果要带数值不确定状态。
4. 因子乘积路径和直接输入最终矩阵的路径必须一致。
5. 未来增加的反例先进入 JSON，再进入自动测试，避免结论只留在聊天记录里。
