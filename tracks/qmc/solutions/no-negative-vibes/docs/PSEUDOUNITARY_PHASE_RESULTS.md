# `U(p,q)` 权重相位的完整初等分类

## 结论

令

```text
D^dagger eta D = eta,
eta = diag(I_p, -I_q),
w(D) = det(I + D).
```

则

```text
conjugate(w) = det(D)^(-1) w.                         (1)
```

因此当 `w != 0` 时，

```text
arg(w) = arg(det(D))/2    modulo pi.                  (2)
```

也就是说，`U(p,q)` 权重的连续复相位完全由群元素的中心 `U(1)` determinant 决定；除此
以外只剩一个实数正负号。

## 证明

由伪酉条件，

```text
D^dagger = eta D^(-1) eta^(-1).
```

所以

```text
conjugate(w)
  = det(I + D^dagger)
  = det(I + D^(-1))
  = det(D)^(-1) det(I + D).
```

这里第二个等号使用了相似变换不改变 determinant，第三个等号把 `D^(-1)` 提出。

对 QMC 乘积

```text
D = product_l exp(A_l),
```

还有

```text
det(D) = exp(sum_l trace(A_l)),
```

因此

```text
arg(w) = Im(sum_l trace(A_l))/2    modulo pi.
```

非交换矩阵的乘积次序不会影响这一中心相位公式。

## 这算不算无符号

不算。公式只把问题分成：

```text
已知的连续 U(1) 相位 × 未知的 Z2 正负号。
```

- 在 `SU(p,q)` 中 `det(D)=1`，所以权重为实数，但可以为负；
- 对 `p,q >= 1`，把已有的 `SU(1,1)` 精确负例嵌入更高维即可得到负权；
- `U(n,n)` 的中心元素已经能让 `arg(w)` 扫过整个圆周，所以单 flavor 没有更窄的普遍相位区；
- 若两个 flavor 的权重互为复共轭，总权重变成 `|w|^2 >= 0`，但这是已知 flavor 配对机制；
- 若 HS 标量前因子恰好抵消中心相位，只会把问题降成剩余的实符号问题，并不会自动消灭它。

因此主办方提出的“`U(n,n)` 相位是否受限”可以用式 (1) 精确回答，但它没有产生新的单 flavor
无符号类。这个结论与已有 `SU(p,q)` 实权结果相邻，应作为排重地基而不是新颖性主张。

## 项目证据

- `U(2)`、`U(1,1)` 扫描样本全部为复权；
- 两类都有机器可读精确复相位证书；
- 通用维数回归测试检查 `U(1,1)`、`U(2,2)`、`U(3,3)` 多层乘积满足式 (1)；
- `SU(1,1)`、`SU(2,1)` 已有精确负权证书，说明去掉连续中心相位后仍可能有负号。

相关既有应用可参见
[Xu et al., PRX 9, 021022 (2019)](https://arxiv.org/abs/1807.07574) 的 `SU(p,q)`
实权与偶 flavor 处理。
