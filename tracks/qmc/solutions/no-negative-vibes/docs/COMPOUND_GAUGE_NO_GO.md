# 复合矩阵规范与普通 hopping 图的 no-go

更新时间：2026-07-28

## 为什么要比 TN 再放宽一步

对单粒子传播子 `D`，

```text
det(I+D) = sum_(k=0)^N Tr[exterior_power_k(D)].
```

TN 要求每个外幂矩阵在标准子集基中的**全部**矩阵元非负。其实可以允许每个粒子数扇区
各自选择一个固定符号规范 `S_k`，只要求每个时间片满足

```text
S_k exterior_power_k(B_l) S_k^-1 >= 0
```

（逐元非负）。外幂保持乘法，非负矩阵也对乘法封闭，而且 trace 不受相似变换影响，所以

```text
Tr[exterior_power_k(B_1...B_L)] >= 0
```

对每个 `k` 都成立，最终仍有 `det(I+D)>=0`。

这个“各粒子数扇区独立规范”的条件严格地说比在一个固定单粒子排序中要求 TN 更灵活。
它也是把“费米子交换符号能否整体规范掉”变成可执行图问题的最小语言。

## 符号图判据

给定无向 hopping 图 `G` 和 `k` 粒子占据子集 `C`。若沿一条边把占据的 `j` 移到空的
`i`，外幂基中的矩阵元符号是

```text
(-1)^(position(j in C) + position(i in C-j+i)).
```

以所有 `k` 元子集为顶点、合法单粒子移动为边，就得到一个 signed configuration graph。
存在固定对角符号规范把全部 hopping 变为非负，当且仅当这个 signed graph 是 balanced：
任意闭环上的符号乘积都为正。代码用一次 BFS 传播 `+/-1` 规范并检查冲突，无需数值优化。

## 一般图论结论

对普通数守恒 hopping，所有粒子数扇区都可规范为非负，当且仅当每个连通分量是一条开放
路径。

证明骨架很短：

1. 若图是若干路径，把每条路径连续排序；最近邻移动不跨过其他站点，所有扇区直接非负。
2. 若某个顶点度数至少为三，图含 `K_(1,3)` 星形子图。两个费米子可借第三条空支路交换，
   配置空间中产生奇交换闭环，环符号为负。
3. 若所有度数至多二但某个连通分量不是路径，它必含一个环。两个粒子可沿环交换而不相撞，
   同样产生负闭环。

额外图边不能消除一个已经存在的负闭环。因此普通 hopping 的交换拓扑，而不只是 TN
技术本身，迫使所有可全扇区消符号的连通图退化成开放路径。

这个结论不要包装成新的图论定理认领；它与图上的粒子交换/配置空间拓扑密切相关。对本项目
真正重要的是：它关闭了“换一个更聪明的外幂符号规范，也许环或分支会活下来”的退路。
图 braid group 文献也把 junction 上的粒子交换和沿简单环的 circular move 作为基本
生成元，见 [An and Maciazek, 2021](https://arxiv.org/abs/2006.15256)。

## 全图穷举

运行

```bash
python3 -m oracle.compound_gauge --max-sites 6
```

得到所有标号连通简单图的完整枚举：

| 站点 | 连通图总数 | 全扇区可规范非负 | 标号路径数 `N!/2` |
|---:|---:|---:|---:|
| 2 | 1 | 1 | 1 |
| 3 | 4 | 3 | 3 |
| 4 | 38 | 12 | 12 |
| 5 | 728 | 60 | 60 |

每个规模的幸存数都与标号开放路径数完全相同，没有一个非路径图幸存。穷举不是一般证明，
但它独立检查了符号公式、最小 forbidden motifs 和一般图论判断。

## 对物理搜索意味着什么

以下三条路线现在已经被区分开：

1. **普通 fermion hopping，无额外编码：关闭。** 连续 TN、TN 正和以及逐扇区独立符号
   规范最终都只能得到路径。
2. **带宇称串的相关 hopping：仍开放。** 例如在远邻 hopping 上乘
   `product_(i<r<j)(1-2n_r)` 可抵消 Jordan--Wigner 占据符号，但这已经是多体相关
   hopping，不是普通二次 Hamiltonian；还要检查它能否由正高斯和实现。
3. **改变 Hilbert 空间或权重对象：仍开放。** 非平凡 ancilla/gauge constraint 编码、
   pairing/Majorana/Pfaffian、或比正外幂锥更一般的 cone-preserving semigroup，可能
   绕过本页假设。

简单地加入并在 Fock 基中投影/迹掉一个普通 ancilla 仍只会对非负矩阵元做非负求和，不能
消除普通远邻 hopping 已有的负矩阵元。ancilla 只有在配合非平凡编码、规范约束或改变物理
费米子定义时才值得继续。
