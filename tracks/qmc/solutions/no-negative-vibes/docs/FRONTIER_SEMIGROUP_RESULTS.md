# 新半群候选快速初筛结果

更新时间：2026-07-28

## 结论

两轮本机扫描共检查 `1,392,000` 个行列式权重，不需要超算：

- 15 个候选/对照族的广扫：720,000 个权重，累计 CPU 时间约 306 秒；
- 三个混合 split-cone 族的压力扫描：672,000 个权重，累计 CPU 时间约 602 秒；
- 所有 2,112 个参数格点完整结束，结构残差均为零，没有失败格点。

最重要的产出不是某个“零负例率”，而是两条可证明的结论：

1. 三对角 Metzler 路径生成元属于全非负矩阵半群，任意维数和深度都有
   `det(I+D) >= 1`；
2. 两个夹角任意小但不相同的 split-contraction 锥的并集都不是恒正类，存在显式两层
   反例。


## 任意非平凡夹角的解析反例

在一个正度量方向和一个负度量方向组成的二维子空间中，令

```text
eta = diag(1,-1),
N   = [[ 1,  1],
       [-1, -1]],
A_1 = q N,
A_2 = q R(theta) N R(theta)^T.
```

`N^2=0`，并且

```text
N^T eta + eta N = 2 [[1,1],[1,1]] >= 0.
```

因此 `A_1` 在第一个 split cone 的秩一边界上，`A_2` 在旋转后 cone 的边界上。直接使用
`exp(qN)=I+qN` 可得二维权重

```text
det[I + exp(A_1) exp(A_2)]
  = 4 [1 - q^2 sin^2(theta)].
```

嵌入 `eta=diag(1,1,-1,-1)` 后，另外两个恒等方向再贡献因子 `4`：

```text
w_4d = 16 [1 - q^2 sin^2(theta)].
```

所以只要 `sin(theta) != 0`，取 `q > 1/|sin(theta)|` 就得到严格负权。若把不同 cone 的
主夹角限制在 `0<theta<pi`，这就覆盖全部情形；角度缩小时，反例所需尺度按
`1/|theta|` 增长，精确解释了“小角越小，随机反例越少”的现象。

实现和回归测试位于
`oracle/frontier_candidates.py::mixed_split_boundary_counterexample` 与
`tests/test_frontier_candidates.py`。

## 现在保留什么

### 主候选

全非负路径半群。它已有一般证明、明确边界和两个 HS 最小模型，详见
[全非负路径半群](TOTAL_NONNEGATIVE_PATH_CLASS.md)。

### 正对照，不作为新类

- 一个固定 split-contraction cone；
- block-upper-triangular 的行列式因子化；
- 固定路径符号规范；
- 开放一维 Hubbard 链本身。

### 已关闭

- 环、星形和稠密 Metzler 图的朴素推广；
- 每片独立路径符号规范；
- 任意双向分块耦合；
- 任意两个不同旋转 split cones 的完整并集。

## 算力判断

这阶段的瓶颈是候选定义、解析结构和对抗采样，不是吞吐量。当前 139.2 万个权重总 CPU
时间约 15 分钟；即使并行后扩大十倍，本机也足够。现在上超算只会更快地产生重复随机
样本，不会替代：

- 已知类排重；
- 低秩/边界对抗构造；
- 一般证明；
- Hamiltonian 到 HS 矩阵的物理映射。

只有出现一个没有证明、没有反例、具有明确物理来源且需要随系统尺寸研究稀有失败率的候选，
才值得申请超算。
