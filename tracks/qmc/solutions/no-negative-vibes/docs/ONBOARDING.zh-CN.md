# 无符号问题猎手：零基础入门与开工地图

这份说明面向“会普通蒙特卡洛，但还不会量子蒙特卡洛、群论和行列式
QMC”的队员。技术证据和论文链接见
[FOUNDATIONS.md](FOUNDATIONS.md)。

## 1. 我们到底在解决什么

普通蒙特卡洛需要从非负概率分布采样。假设一个配置 `C` 的权重是
`w(C)`，理想情况是

```text
w(C) >= 0,
Z = sum_C w(C).
```

如果 `w(C)` 有正有负，我们只能按绝对值 `|w(C)|` 采样，再把符号放进
观测量：

```text
<O> = <O sign(w)>_|w| / <sign(w)>_|w|.
```

系统变大或温度降低时，平均符号通常指数变小。分子和分母都来自大量正负
抵消，误差却被 `1/<sign>` 放大。这就是费米子符号问题：算法形式上仍然
正确，实际计算成本却变成指数级。

## 2. 为什么量子多体问题会变成一个矩阵行列式

费米子哈密顿量含有四次相互作用，例如 Hubbard 模型中的
`U n_up n_down`。行列式 QMC 先做三步：

1. 把逆温 `beta` 切成很多虚时间片；
2. 用 Hubbard--Stratonovich 变换，把四次相互作用换成费米子与辅助场的
   二次耦合；
3. 对二次费米子自由度做解析求和，只留下辅助场。

固定一条辅助场历史后，每个时间片都对应一个单粒子矩阵指数
`exp(A_l)`。把所有时间片按顺序相乘并积掉费米子，得到

```text
w = det(I + exp(A_1) exp(A_2) ... exp(A_L)).
```

因此这个挑战不是先写一个完整的 Hubbard 模型模拟器，而是先问一个更基础
的数学问题：

> 对什么结构化矩阵集合，任意深度、任意顺序的指数乘积都保证这个行列式
> 非负？

一旦找到这种集合，再把 `A_l` 解释成具体模型的 hopping、pairing 和辅助场
顶角，就得到一族无符号问题的 QMC 算法。

## 3. 为什么这很适合 AI agent

这个问题同时有快速实验和严格证明两端。

- 提出一个矩阵结构后，数值程序可以立即随机生成矩阵并寻找负权重；
- 找到浮点负例后，可以继续搜索有理数或符号化的精确证书；
- 如果几百万个样本都没有负例，就尝试从特征值配对、对称性或半群结构证明；
- 每个候选都能自动与已知充分条件比较，过滤重复发现。

AI 很适合提出候选、写扫描程序、缩小反例和整理文献。真正困难、也最有
科研价值的环节是：证明“所有矩阵、所有乘积深度”都成立，并找到物理模型
实现。

## 4. 现在已经知道的三条主线

### 分裂正交群

定义

```text
eta = diag(I_n, -I_n).
```

如果每个生成元满足

```text
A^T eta + eta A = 0,
```

那么每个 `exp(A)` 都保持这个不定度量，乘积落在 `O(n,n)` 的恒等连通分支，
并且行列式权重非负。这是挑战的第一个已知基准。

### Kramers / Majorana 对称

另一类证明不直接研究矩阵所在的实李群，而是利用反幺正对称性。粗略地说，
如果特征值被强制成复共轭对，且实特征值也有合适的偶重简并，行列式就成为
非负因子的乘积。

2016 年的工作已经给出了 Majorana 和 Kramers 两个基本无符号对称类。因此
以后看到“特征值成对”时，第一反应应该是检查它是否只是这个已知机制。

### 收缩半群

等式还能放宽为

```text
A^T eta + eta A >= 0.
```

这时矩阵指数不再组成群，因为逆元通常不满足同一不等式；它们组成只要求
乘法封闭的半群。这个条件覆盖的范围更大，也是 2024 年系统框架的核心。

## 5. 我们已经得到的第一个精确结果

挑战建议先检查实辛群 `Sp(2n,R)`。最低维时

```text
Sp(2,R) = SL(2,R).
```

定义两个剪切矩阵

```text
U(x) = [[1,x],[0,1]],
L(y) = [[1,0],[y,1]].
```

它们都是辛李代数中幂零矩阵的指数，而且当参数是有理数时，所有元素都是
有理数。直接相乘：

```text
U(-3) L(1) U(-3/2) L(2)
    = diag(-2,-1/2).
```

因此

```text
det(I + D) = (1-2)(1-1/2) = -1/2.
```

这不是浮点近似，而是完整的有理数反例。把它与恒等矩阵做直和，还能得到
任意更高维 `Sp(2n,R)` 的负例。所以“整个实辛群是否保证非负”这条路线已经
可以严格关闭。

这个结果本身大概率不是新定理，但它非常有用：

- 它满足主办方对精确反例的格式要求；
- 它是数值 oracle 必须识别出来的负控制；
- 它展示了从随机猜测到精确证书的完整工作流。

## 6. 伪酉群方向为什么要谨慎

对 `D in U(p,q)`，我们推得

```text
conj(det(I+D)) = det(D)^(-1) det(I+D).
```

所以权重相位被限制为 `det(D)` 相位的一半，但符号不一定为正。若
`D in SU(p,q)`，行列式确实为实数；2019 年论文已经证明了这点，并用偶数个
相同费米子味把实数权重平方成非负数。

我们还把辛群有理负例通过固定基变换变成了 `SU(1,1)` 有理负例。因此：

- “`SU(p,q)` 的权重是实数”已有文献；
- “偶数味权重非负”已有物理应用；
- “单味权重总是非负”是错的；
- 真正可能的新问题只能是更细的子类、相位可吸收条件，或新的半群锥。

## 7. 你现在需要学到什么程度

第一天不需要系统学习李群或 Majorana 场论。先掌握四个可操作概念：

1. 能解释辅助场历史为什么给出矩阵乘积；
2. 能区分“数值没找到负例”和“已经证明非负”；
3. 能检查一个候选是否满足给定的矩阵等式或半正定不等式；
4. 能读懂精确证书中每一步为什么保持候选结构。

随后再按任务补知识：

- 负责数值的人学习 NumPy/SciPy、矩阵指数、`slogdet`、条件数和高精度复核；
- 负责理论的人学习特征值配对、`O(p,q)`、`U(p,q)`、`Sp(2n,R)` 和连通分支；
- 负责物理的人学习 Hubbard--Stratonovich 分解以及 hopping/pairing 矩阵如何
  进入 `A_l`。

两个人时，建议一人主数值与精确证书，一人主文献与物理映射；每天交换一次
角色，避免代码和物理完全脱节。

## 8. Oracle 的合格标准

第一版程序至少要做到：

- 固定随机种子后完全可复现；
- 生成矩阵时记录结构残差，而不是只相信生成公式；
- 扫描矩阵维度、乘积深度和多个独立样本；
- 同时记录行列式符号、对数绝对值和条件数；
- 接近零或病态的结果标记为“不确定”，用更高精度复核；
- 已知正例、负例和零例都进入自动测试；
- 任何最终反例都另给 SymPy 有理数或符号证书。

程序通过以下基线才算拿到挑战的“入场券”：

1. `O(1,1)` 四个连通分支分别给出正、负、零、零；
2. 随机 split-orthogonal 生成元乘积不出现负权重；
3. 随机半群锥生成元乘积不出现负权重；
4. 精确识别上面的 `Sp(2,R)` 负例；
5. `SU(1,1)` 单味负例为负，偶数味平方为正。

## 9. 明天的合理目标

不要把“找到全新无符号物理模型”设为第一天目标。第一天完成下面三件事就有
高质量进展：

1. 两位队员都能用自己的话讲清楚挑战对象和已知三条理论线；
2. oracle 的测试规格得到确认，并开始按红--绿--重构写实现；
3. 从经典群表中选一个非常窄的下一候选，先做已有工作约化，再做随机扫描。

首选策略是“两条腿走路”：

- 保守线：完成可靠 oracle、精确证书和已知结果复现，保证最终有可交付成果；
- 探索线：在伪酉相位约束或一个明确的半群扩展上寻找真正的新结论。

这样即使探索线最后被反例或已有文献关闭，整个项目仍然有完整、可复现并且
有方法价值的结果。
