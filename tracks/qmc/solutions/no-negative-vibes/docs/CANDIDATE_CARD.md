# 候选矩阵类评估卡

每个候选复制一份本卡再开始扫描。没有填完“结构定义”和“物理来源”的候选，只能算数学玩具，
不能算挑战答案。

## 1. 候选定义

- 名称：
- 数域与矩阵维数：
- 固定度量、反幺正算符或其他结构：
- 单时间片生成元 `A_l` 的精确定义：
- 允许的参数范围：
- 乘法/指数下是否封闭：
- 希望证明的命题：

## 2. 为什么可能非负

- 谱如何配对：
- 实特征值或单位圆特征值如何处理：
- 零点能否穿越并改变符号：
- 当前是定理、猜想，还是数值直觉：

## 3. 已知机制排重

逐项给出“属于 / 不属于 / 尚未判断”和证据：

- split-orthogonal 或换基后的 split-orthogonal；
- Majorana reflection positivity；
- Majorana/Kramers 对称类；
- contraction-semigroup 条件；
- 复制 flavor 后的平方、共轭配对或显然加倍；
- `SU(p,q)` 的实权机制或 `U(p,q)` 的固定相位机制；
- 已有论文中同一条件的不同记号。

只要可逆换基、直和或 flavor doubling 就能还原到已知类，默认不算新类。

## 4. 最小维数检验

- 第一个非平凡维数：
- 可手算的特殊子族：
- 已知正、负、零控制：
- 精确枚举/符号计算计划：
- 数值扫描轴：维数、深度、尺度、随机种子：
- 结构残差和高精度复核规则：

发现一个精确负权例即可淘汰“全体非负”命题。扫描没有发现负数只能把候选标记为
`numerical survivor`，不能标记为 `sign-free`。

## 5. 物理 DQMC 映射

- 费米子哈密顿量：
- 格点、边界和 flavor 数：
- 相互作用项：
- Hubbard–Stratonovich 分解：
- 每个辅助场构型对应的 `A_l`：
- 候选约束为什么对每个时间片都成立：
- 是否引入复数耦合、非局域项或不可采样权重：
- 除行列式外的辅助场前因子及其符号/相位：
- 最小可运行物理实例：

## 6. 状态与停止条件

状态只使用以下标签：

- `untriaged`：尚未完成排重；
- `known-mechanism`：落入已有定理；
- `exact-counterexample`：已有精确负例；
- `numerical-survivor`：扫描暂未找到负例；
- `proof-candidate`：有清晰证明路线；
- `physical-candidate`：有逐时间片的 DQMC 映射；
- `challenge-ready`：同时具备新颖性、数学证据和物理映射。
