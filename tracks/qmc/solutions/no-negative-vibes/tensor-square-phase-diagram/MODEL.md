# Model Definition and Physics Targets

## 1. 单粒子空间与哈密顿量

取一个实的 `m` 维基空间 `V`，费米子单粒子空间为 `V ⊗ V`。模式写成 `c†_{ij}`，其中 `i,j=1,...,m`，总模式数为 `m²`。

对任意实矩阵 `A` 定义 Kronecker-sum 生成元

```text
M_A = A ⊗ I + I ⊗ A
Q_A = dΓ(M_A) = Σ_{αβ} (M_A)_{αβ} c†_α c_β .
```

若 `A=Aᵀ`，则 `Q_A` 厄米。主模型族取

```text
H = dΓ(k ⊗ I + I ⊗ k)
    - (1/2m) Σ_e g_e Q_{A_e}² ,
```

其中 `k=kᵀ`、`A_e=A_eᵀ`、`g_e ≥ 0`。当通道数随 `m` 线性增长且每个 `Q_e` 含 `O(m)` 项时，`1/m` 是自然的 Kac 归一化；代码仍应数值检查能量密度是否随 `m` 收敛。

化学势保持在同一结构内：在 `k` 中加入 `-μI/2`，即可在 `k⊗I+I⊗k` 中产生 `-μI`。

## 2. 为什么辅助场权重非负

对负平方相互作用使用实高斯 Hubbard–Stratonovich 场。单个时间片的一体演化保持为

```text
B_ℓ = X_ℓ ⊗ X_ℓ ,
```

因为

```text
exp(A ⊗ I + I ⊗ A) = exp(A) ⊗ exp(A),
(X₁ ⊗ X₁)(X₂ ⊗ X₂) = (X₁X₂) ⊗ (X₁X₂).
```

整段虚时间历史因此仍为 `B = X ⊗ X`，其中 `X` 为实矩阵。费米子迹的行列式满足

```text
det(I + X ⊗ X)
  = |det(I + iX)|² · det(I + ∧²X)²
  ≥ 0.
```

等价地，若 `λ_i` 是 `X` 的特征值，则

```text
det(I + X ⊗ X)
  = Π_i (1 + λ_i²) · Π_{i<j}(1 + λ_iλ_j)² .
```

这给出逐辅助场构型的非负权重，不依赖两个相同物种的简单块复制，也不要求固定 Kramers 反幺正对称。

### 必须冻结的正确性条件

- 所有进入时间片的一体生成元都必须具有同一个 `A⊗I+I⊗A` 结构。
- `X` 必须在选定固定基中为实矩阵。
- 数值实现不得把两个 tensor factor 独立扰动。
- 若将 `Q_A²` 改写为正规序两体项，必须保留收缩产生的一体修正。最安全的基准定义始终是完整的 `Q_A²`。

## 3. 物理解释

展开 `Q_A`：

```text
Q_A
 = Σ_{ijk} A_{ik} c†_{ij}c_{kj}
 + Σ_{ijl} A_{jl} c†_{ij}c_{il}.
```

同一个 `A` 同时作用在两个指标上，因此可把 `c_{ij}` 看成：

- 定向顶点对上的 rank-2 / matrix fermion；
- 或 `m×m` product lattice 上的费米子，行与列方向被同一辅助场同步驱动。

典型通道：

- `A=diag(a_i)`：`Q_A=Σ_{ij}(a_i+a_j)n_{ij}`，对应行/列密度多极矩、轨道或 nematic 序。
- `A_{rs}=E_{rs}+E_{sr}`：同时驱动第一个和第二个指标上的对应键跃迁；`Q_A²` 产生键-键耦合、关联跃迁、密度辅助跃迁和数守恒的 pair-hopping 成分。
- 多个互不对易的 `A_e`：产生竞争的量子序参量，避免把问题退化为一个可同时对角化的经典密度模型。

非局域性不是缺陷：`Q_e²` 将 product lattice 上多个 row/column fiber 耦合起来。研究问题是这种由恒正表示结构保护的集体相互作用是否稳定出新的有序相、混合序或临界行为。

## 4. 首个可计算模型

### 最小机制演示：m=3

```text
A₁₂ = E₁₂ + E₂₁
A₂₃ = E₂₃ + E₃₂
```

`[A₁₂,A₂₃] ≠ 0`，因此两个相互作用通道不能同时对角化。取一个不与二者全部对易的实对称 `k`，扫描：

```text
g₂/g₁,  t/g₁,  μ/g₁,  βg₁ .
```

该 9 模式模型只用于 ED、oracle 和 QMC 正确性验证，不用于宣称热力学相。

### 可扩展 product-graph 模型

令基础图 `G_m` 有 `m` 个顶点。对每条边 `e=(r,s)` 定义

```text
A_e = E_rs + E_sr .
```

建议从周期链和稀疏非正则图两类开始：

```text
k = -t Σ_e A_e + Σ_r v_r E_rr - (μ/2)I,
H_int = -(1/2m) Σ_e g_e Q_e².
```

优先使用交替或分组耦合 `g_e`，以及与相互作用通道不完全对齐的 `v_r` 或次近邻 `k`，形成可控的竞争。保留一个均匀极限作为基准，但不要把完全均匀的全 Lie 代数基、Casimir 极限或单一全局通道当作最终模型。

## 5. 相图轴和观测量

主扫描轴：

- 相互作用比 `g_B/g_A`；
- 动能比 `t/g_A`；
- 化学势或填充；
- 温度 `T/g_A`；
- 可选的交替势、次近邻跃迁或通道各向异性。

最低观测量：

- 能量、密度、压缩率和双占据的适当 rank-2 类比；
- `⟨Q_e⟩`、`⟨Q_eQ_f⟩`、通道 susceptibility；
- row/column density 与 nematic structure factor；
- bond-order structure factor；
- 单粒子关联、动量分布和有限尺寸 gap proxy；
- pair/correlated-hopping susceptibility；
- Binder ratio、相关长度比和温度/尺寸 crossing；
- Monte Carlo 符号的直接审计，理论上应恒为 `+1` 或零权重。

## 6. 论文创新需要回答的问题

以下是待验证假设，不是已经成立的结论：

1. tensor-square 表示是否给出文献中未系统识别的可扩展 sign-free Hamiltonian 家族？
2. 该家族是否存在不能由自由极限、单通道 Hubbard–Stratonovich 平均场或 Casimir 简化解释的相？
3. 同步 row/column 动力学是否产生 matrix-fermion 特有的混合序、维数约化或非常规临界性？
4. 结构化权重计算能否把 `m²×m²` 的朴素代价降低到以 `m×m` 运算为主，从而同时构成算法贡献？

任何“新机制”或“新相”的表述都必须在文献检索、对称性分析、有限尺寸标度和至少一个独立数值交叉检查之后使用。
