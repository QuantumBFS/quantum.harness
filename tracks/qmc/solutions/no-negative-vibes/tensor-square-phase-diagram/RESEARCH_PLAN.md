# Research Plan

## 总目标

构造并验证一个 tensor-square sign-free 费米子模型；用 ED 和结构化 determinant QMC 得到可信相图；筛选至少一个具有非平凡物理解释的候选相或临界区域；形成可投稿论文所需的机制、算法、数据和可重复代码。

本计划已经获得项目负责人批准。执行智能体不需要为常规参数调整反复等待确认，但必须在 `STATUS.md` 写清每次采用的哈密顿量、边界、填充、温度、尺寸和观测量。

## 工作循环

每轮严格执行：

```text
假设 → 最便宜的区分性实验 → 正确性门 → 早停或扩展
     → 更新 STATUS.md → 保存小型结果摘要 → Git commit/push
```

失败点只记录足以避免重复的原因。除非它直接否定整个模型族，不做一般性的 no-go 证明。

## Stage 0 — 冻结代数 oracle 与模型约定

任务：

1. 固定 `Q_A=dΓ(A⊗I+I⊗A)`、`H_int=-(g/2m)Q_A²` 和化学势约定。
2. 对 `m=2,3,4` 的随机实时间片，同时计算：
   - 直接 `det(I+X⊗X)`；
   - `|det(I+iX)|² det(I+∧²X)²`；
   - 特征值乘积公式。
3. 测试非对易时间片的闭包、数值极端尺度和接近零权重。
4. 构造多体矩阵，检查 `H=H†`、粒子数守恒和正规序改写。

通过门：

- 三种权重在设定容差内一致；
- 所有抽样权重非负，负值只允许是舍入量级并记录阈值；
- 多体 Hamiltonian 厄米残差达到机器精度量级。

只有 oracle 不一致或模型不厄米才暂停后续工作。

## Stage 1 — 小尺寸 ED 物理侦察

尺寸：

- `m=3` 全谱；
- `m=4` 优先按粒子数分块稀疏对角化。

任务：

1. 扫描粗网格 `g_B/g_A`、`t/g_A`、`μ/g_A`。
2. 计算基态能量、gap、密度、`Q` 通道关联、row/column nematic、bond order 和 pair/correlated-hopping 关联。
3. 对每个候选区域比较：
   - 自由极限；
   - 单通道极限；
   - 可同时对角化通道；
   - 完全均匀高对称极限。

成功门：

- 找到至少一个在加入第二个非对易通道后出现明显 avoided crossing、序参量重排或 gap 结构变化的区域。

早停：

- 单个参数点若只复现自由或单通道行为，记录后跳过；
- 若整个首个图族过于对称，立即转向交替耦合或非正则基础图，不证明 no-go。

## Stage 2 — DQMC 原型与 ED 交叉验证

先实现正确的朴素版，再优化：

1. 连续高斯 HS 或等价严格分解，每个时间片显式形成 `X_ℓ⊗X_ℓ`。
2. 小 `m` 使用完整 `m²×m²` 矩阵计算权重和 Green function。
3. 同时使用 tensor-square 因子公式计算权重，逐样本比较。
4. 在 `m=3,4` 与 ED 比较能量、密度和至少一个非平凡关联函数。
5. 测试 Trotter 步长、热化、binning、自相关与多个种子。

通过门：

- QMC 与 ED 在合并统计误差和 Trotter 外推误差内一致；
- 采样期间不存在物理尺度的负权重；
- 重复种子规则和 checkpoint/resume 已工作。

优化目标：

- 权重路径尽量只操作 `m×m` 的 `X`；
- 对结构化观测量避免无条件构造所有 `m²×m²` 中间量；
- 为朴素版和结构化版提供一致性测试与运行时间/内存基准。

## Stage 3 — 低成本相图侦察

首轮建议网格：

```text
m = 4, 6, 8
βg_A = 2, 4, 8
g_B/g_A = 0, 0.25, 0.5, 1, 2
t/g_A = 0, 0.25, 0.5, 1, 2
填充 = 半填充附近 + 至少两个非半填充点
```

先为每个 cell 运行短链：

- 只要能区分平庸区、候选有序区和可能的 crossing；
- 监控接受/更新效率、积分自相关时间、误差和结构因子；
- 参数 cell 完全独立，以多进程并行。

幸存条件满足任一即可进入密集扫描：

- 结构因子随 `m` 增强并与高温背景明显分离；
- 两种竞争序参量发生清晰重排；
- gap proxy、压缩率或相关长度比出现尺寸一致的异常；
- 出现不能由单通道/自由/高对称基准解释的稳健混合响应。

早停：

- 热化后信号始终小于两倍误差且尺寸无趋势；
- 自相关代价远高于信号价值；
- 与已知平庸基准在所有主观测量上不可区分。

## Stage 4 — 幸存者密集扫描

对每个幸存区域：

1. 缩小到一至两个最有区分力的参数轴。
2. 增加 `m`、`β`、统计量和参数分辨率。
3. 计算序参量 susceptibility、Binder ratio、相关长度比、能量导数和迟滞。
4. 同时保留自由、单通道和高对称对照线。
5. 若疑似一阶，检查双峰、迟滞和体积标度；若疑似连续，寻找 crossing 和数据塌缩窗口。

每个候选相必须写一页机制摘要：破缺的对称性、主要自由度、最简有效描述、排除的平庸解释、仍可能的替代解释。

## Stage 5 — 有限尺寸标度与独立检查

最低要求：

- 至少 4 个尺寸；
- 最低温度对目标相已基本收敛，或明确做量子临界 `β∝m^z` 路线；
- 报告自相关、有效样本数、Trotter 外推或连续时间控制；
- 使用 ED、不同更新方案、不同图族或独立实现中的至少一种做交叉检查；
- 对临界点和指数报告拟合窗口敏感性，不只给最佳拟合。

## Stage 6 — 论文包

输出：

- 一页 sign-free 定理与适用条件；
- Hamiltonian、对称性、极限和物理实现解释；
- 结构化 QMC 算法与复杂度基准；
- 相图总览、候选相诊断、有限尺寸标度和误差表；
- 文献新颖性矩阵：普通 flavor square、Majorana/Kramers 类、split orthogonal、fermion bag、representation-induced square；
- 可重复脚本、环境、参数 manifest、种子和小型 golden data；
- 已知局限与下一步。

## 计算量判断

- `m=3` ED（512 维全 Hilbert 空间）几乎即时。
- `m=4` 全空间 65536 维，稀疏 ED 和固定粒子数分块可在普通工作站完成。
- `m=5` 全空间约 3355 万维，完整 ED 已不划算，只做强分块或停止 ED 扩展。
- QMC 若朴素操作 `m²×m²` 矩阵，单步近似按 `m⁶` 增长；结构化权重可望把主要权重计算降到以 `m³` 为主，部分观测量约 `m³–m⁴`。

预期：

- 代数验证、ED 侦察和 QMC 小尺寸对照：数小时到 1 天。
- 首轮并行粗扫描：约 1–3 天，取决于实现和自相关。
- 论文级低温、多尺寸标度：数天到两周。

现有 16 线程/31 GiB WSL 机器与 64 线程/503 GiB CPU 机器足够做第一阶段和中等规模扫描。真正瓶颈更可能是算法实现、热化和自相关，而不是原始核数或内存。
