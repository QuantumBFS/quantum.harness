# Stage 1 ED 侦察记录

日期：2026-07-29

## 计算约定

- `m=3`：P3 开链，`A12` 与 `A23` 两个非对易通道；为停止对称种子的机器零 gap 假信号，固定加入 `v/g_A=0.15·diag(-1,0,1)`。
- `m=3` 同时计算 grand-canonical 扇区选择与固定 `N=4,5`；所有简并基态观测量取基态子空间平均，gap 指向首个不同能级。
- `m=4`：C4 周期链，交替边集合 A/B，固定半填充 `N=8`；局部非对易响应按所有 A-B 边对的 `⟨(i[Q_a,Q_b])²⟩` 平均。
- 网格：`t/g_A=0,0.25,0.5,1,2`，`g_B/g_A=0,0.25,0.5,1,2`；`g_A=1`。

## 正面信号

1. `m=3, N=4` 在 `g_B/g_A≈1` 出现窄 gap 谷和通道重排：
   - `t/g_A=0.5`：gap 从 `0.2384` (`g_B/g_A=0.5`) 降到 `0.02444` (`1.0`)，再升到 `0.3426` (`2.0`)；
   - `t/g_A=1`：对应 gap 为 `0.1500 → 0.01038 → 0.2580`；
   - nematic² 在 `t=0.5` 同期从 `0.1212` 升到 `0.1764`。
2. 可对易控制线在 `m=3,t=0.5,g_B/g_A=1` 的 gap 为 `1.0775`，局部 commutator² 为 `1.95e-32`；非对易模型同点 commutator² 为 `0.0154`。因此 gap 谷不是可对易密度通道的直接复制。
3. `m=4,N=8` 重现竞争：
   - `t=0.5` 的不同能级 gap 为 `0.9783 → 0.5083 → 0.9294`；
   - `t=1` 为 `1.0340 → 0.5072 → 1.9567`；
   - channel balance 在两条线上均跨过 0，局部 commutator² 保持 `O(10^-2)`。

这些是进入 DQMC 验证和粗扫的正面候选，不是热力学相声明。最值得交叉验证的点为：

```text
m=3: t/g_A=0.5, g_B/g_A=1, v/g_A=0.15, μ/g_A=0
m=4: t/g_A=1,   g_B/g_A=1, v=0,           μ/g_A=0
controls: g_B/g_A=0.5, 2 and the m=3 commuting channel
```

## 早停与下一轮调整

- `t=0` 在 `m=3,4` 都由巨大简并与无动能极限主导，标记 `STOP`；不扩展、不做 no-go。
- `m=3,v=0` 对称种子的扇区漂移和向量 fidelity 假异常已停止；后续只使用子空间 fidelity。
- `g_B/g_A=1` 附近既接近更高对称线又出现强 gap 谷，因此下一轮必须保留 `0.5`、`2` 和可对易控制，避免把高对称性本身误判为新相。
