# 奶龙陆战队 — N-queens exact-contraction challenge

## Team

- **Team name:** 奶龙陆战队
- **Members:** 王臻铼，查润德，夏敏恒

## Challenge registration

- **Challenge:** Implement a strictly exact contraction of the Liu–Liao–Wang
  N-queens tensor network, validate known counts through N = 27, and attempt
  Q(28), extending the current exact-enumeration frontier.
- **Catalog issue:** Addresses #34 — released by Hai-Jun Liao, Institute of
  Physics, Chinese Academy of Sciences.
- **Track:** `tracks/peps/`, from the issue's `PEPS Based Algorithm` method
  field.

This folder will contain the reproducible exact-contraction implementation and
its documentation. Generated data and figures will be kept under
`tracks/peps/results/` and are not committed as part of registration.
