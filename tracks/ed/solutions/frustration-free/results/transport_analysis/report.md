# L=8 Rice-Mele-Hubbard 泵输运分析

## 范围与定义

本报告统一分析 `L=8`、半填充、`t=1` 的路径依赖输运，并保留中心路径已有的 `(U,t)` 主扫描。路径写为

\[
\delta(\phi)=0.9\cos\phi,\qquad
\Delta(\phi)=\Delta_c+3\sin\phi,
\]

其中 `Delta_c=0,1.5,2.85,3.6`。晶胞长度为 `d=2a`；半填充时输运电荷 `Q` 对应的质心位移效率为

\[
\eta=\frac{\Delta x_{\rm COM}}{d}=\frac{Q}{2}.
\]

因此 `Q=2` 对应移动一个晶胞，即 `eta=1`。这里的效率不是速度 `d/T`，也不是 `Q/T`。

## 拓扑量、绝热电荷与有限时间电荷

- `C_MB` 是 `(theta,phi)` 环面上的 FHS many-body Chern number。
- `Q_adiabatic(phi)` 按 `36.md` 定义为多体极化的连续变化，数值上由 twist Wilson loop/FHS flux 累积得到；完整有隙周期的终值等于 `C_MB`。
- `Q(T,phi)` 由 `theta=0` 的瞬时基态开始，用 midpoint-Magnus/Krylov 演化并积分同一边界上的电流。
- 窄 twist strip 给出的固定 `theta=0` Berry 响应是有限尺寸诊断量。它在临界点附近可能很大，不等于本报告定义的 `Q_adiabatic`，不进入主图或效率定义。

因此主图用 `Q_adiabatic(phi)` 展示拓扑绝热目标，用 `Q(T,phi)` 展示有限周期实现程度。有限 `L=8`、固定 twist 的动力学与 twist-averaged 极化曲线不要求逐点完全相同；在远离闭隙且系统尺寸、周期足够大时两者才趋于一致。

## 数据与数值方法

中心路径沿用完整运行 `l8-allobs-20260728T230945`：451 个静态结果（41 个 `U` 乘 11 个 `t`）和 1353 个实时结果（`T=2,10,50`）。平移路径沿用 54 个代表性静态点、72 个中心振幅点和 24 个含时点。

本轮没有提交新的超算任务，而是在本地复用既有结果并补充：

- 105 个闭合线 gap 点：中心路径一个、每个平移路径两个临界点，各取 15 个 `U`；
- 28 个 `20x20` 环面：每个临界点两侧各 4 个 `U`，用于验证 `C_MB` 跃迁；
- 16 条固定 twist Berry 响应曲线作为有限尺寸诊断；它们不作为 `Q_adiabatic` 绘图输入。

相变定位利用有限链的高对称闭合点：平移路径的低 `U` 临界位于 `theta=0,phi=3pi/2`，高 `U` 临界位于 `theta=0,phi=pi/2`；中心路径在两个相位同时闭合。这条线用于低成本密扫 gap；拓扑扇区则始终由临界点两侧的完整环面 FHS 计算确认。临界点本身 gap 闭合，Chern number 不定义，图中不为它强行指定整数。

## 核心结果

### 1. 平移路径存在两次拓扑跃迁

加密后得到：

| 路径 `Delta_c` | 低临界 `U_c` | 高临界 `U_c` | 临界序列 |
|---:|---:|---:|:---|
| 0 | 7.372348498 | 同时 | `2 -> 0` |
| 1.5 | 4.352096694 | 10.354477369 | `2 -> 1 -> 0` |
| 2.85 | 0.882883835 | 13.039003998 | `2 -> 1 -> 0` |
| 3.6 | 2.343682390 | 14.531681175 | `0 -> 1 -> 0` |

这修正了旧 `U` 网格给出的粗略判断。例如 `Delta_c=1.5` 的低跃迁不是发生在 `U<4`，而是在 `U≈4.35210`；旧图把稀疏点直接连线，无法显示实际闭合。

### 2. 密扫明确看到 gap 闭合

| 路径 `Delta_c` | 分支 | 拟合 `U_c` 处 gap |
|---:|:---:|---:|
| 0 | simultaneous | `7.80e-9` |
| 1.5 | low | `2.39e-6` |
| 1.5 | high | `1.49e-6` |
| 2.85 | low | `2.45e-7` |
| 2.85 | high | `5.87e-7` |
| 3.6 | low | `9.76e-7` |
| 3.6 | high | `7.59e-7` |

这些残余值来自临界 `U` 只保留有限小数，而不是可分辨的有限 gap。临界两侧的 `20x20` 环面计算给出相邻整数 Chern 扇区，故闭合与拓扑跃迁相互一致。

### 3. 中心路径的拓扑跃迁与有限时间输运分离

`t=1` 的既有中心扫描给出

\[
C_{\rm MB}=2\quad(U\le 7.25),\qquad
C_{\rm MB}=0\quad(U\ge 7.5).
\]

对应环面最小 gap 在 `U=7.25` 和 `7.5` 分别为 `0.06788` 和 `0.06607`。在 `U=0`，`Q(T)` 从 `T=2` 的 `1.09025` 收敛到 `T=50` 的 `1.99979`；但 `U=7.25` 时 `T=2,10,50` 分别只有 `0.47402,0.37277,0.14265`。这说明小 gap 区的当前周期仍未绝热，且相干演化不要求随 `T` 单调靠近极限。

强吸引区也有很长的绝热时间尺度：`U=-32` 虽然 `C_MB=2`，但 `Q(T=50)/2=0.05913`。因此 Chern number 表示 twist-averaged 拓扑能力，不能直接替代有限周期、固定 twist 的器件效率。

按多体极化绕数定义的绝热终点值为：

| 路径 `Delta_c` | `U=0` | `U=7.25` | `U=7.5` | `U=16` |
|---:|---:|---:|---:|---:|
| 0 | 2 | 2 | 0 | 0 |
| 1.5 | 2 | 1 | 1 | 0 |
| 2.85 | 2 | 1 | 1 | 0 |
| 3.6 | 0 | 1 | 1 | 0 |

这些终值逐项等于对应的 `C_MB`。中心路径在 `U=7.25` 的 `Q(T=50)=0.14265` 仍远离绝热目标 2，原因是该点距离闭隙转变很近，当前周期不足以实现绝热跟随。此前画到十量级的曲线来自固定 `theta=0` 的有限尺寸 Berry 响应；它不是 `36.md` 定义的绝热极化电荷，现已从主图移除。

`U=0` 中心路径提供直接校验：`Q_adiabatic=2`，既有 `Q(T=50)=1.99979`，差约 `2.1e-4`。Wilson-loop 曲线同时满足 gauge invariance，完整周期终值与 FHS Chern number 一致。

### 4. 平移路径可形成单电荷泵并增大 gap

在 `U=7.25`，三条平移路径都位于 `C_MB=Q_adiabatic=1` 扇区，其环面最小 gap 分别为 `0.7083,0.6387,0.6586`，约为中心路径的一个数量级以上。已有 `T=10` 演化分别给出 `Q(T)=1.0072,1.0016,0.9952`，已接近绝热目标 1。相比之下，中心路径同点只有 `Q(T=10)=0.3728`，远离绝热目标 2。

外移路径 `Delta_c=3.6` 在 `U=0` 为平庸扇区，但在 `2.34368<U<14.53168` 进入 `C_MB=1`；这是相互作用诱导单电荷泵浦的直接例子。

### 5. 振幅图表示拓扑效率而非固定 twist 动力学效率

振幅扫描使用完整环面量 `C_MB/2`，现标为

\[
\eta_{\rm topo}=C_{\rm MB}/2.
\]

它展示路径振幅如何移动拓扑相边界。绝热拓扑效率由 `Q_adiabatic/2=C_MB/2` 给出；实际有限周期效率由 `Q(T)/2` 给出。

## 数值边界

- 105 个密扫 gap 点位于解析识别的闭合高对称线；远离临界区仍使用完整离散环面的最小 gap。
- `20x20` FHS 结果只取临界点两侧，不在 gap 闭合点计算 Chern number。
- 固定 twist Berry 响应只作为有限尺寸诊断保留，不参与主图中的 `Q_adiabatic` 或效率结论。
- 现有平移路径含时数据只覆盖 `U=0,7.25,7.5,16` 和 `T=2,10`；未计算的长周期行为不从这些点外推。
