# L=8 输运物理可视化设计

## 目标

以输运过程为主线，联合展示泵浦路径、周期内累计电荷、有限周期效率、many-body Chern number 和最小能隙。效率定义为

\[
\eta=\frac{\Delta x_{\rm COM}}{d}=\frac{Q}{2},\qquad d=2a.
\]

因此理想自旋双分量泵浦的 `Q=2` 对应 `eta=1`。

## 数据范围

- 系统固定为 `L=8`、半填充、`t=1`、`delta0=0.9`。
- 原点中心、`Delta0=3` 的 41 个 `U` 点复用已完成结果，不重算。
- `Delta0` 使用 `(0.5, 0.75, 1.0, 1.5, 2.0, 2.5, 3.0, 4.0, 5.0, 6.0)`；除 `3.0` 外补算全部 41 个 `U`。
- 路径写为 `delta=delta_c+delta0*cos(phi)`、`Delta=Delta_c+Delta0*sin(phi)`。固定 `Delta0=3`，比较 `Delta_c=0, 1.5, 2.85, 3.6`，分别代表中心、偏心且包围、近临界、不包围路径。中心路径复用旧数据。
- 偏心路径取代表性 `U=(-8, 0, 6, 7, 7.25, 7.5, 8, 16)`；有限周期取 `T=(2,10,50)`。

## 数值与复用

- Hamiltonian、twist、FHS orientation 和 current convention 均不改变。路径中心只改变瞬时 `delta(phi), Delta(phi)`。
- 每个新静态点使用嵌套 `5 -> 10` FHS 网格并保留基态 checkpoint；已有中心路径 checkpoint 原样复用。
- 每个静态结果保存完整 `P(phi)`，每个实时结果保存完整累计 `Q(phi)`，图中的过程曲线来自原始数组。
- 离散结果点必须可见；二维底色可插值，但不得用插值值宣称相边界或量子化结果。

## 输出图组

1. 路径图和一个周期内 `Q_ad(phi)`、`Q_T(phi)`。
2. `eta(U)=Q(U)/2` 曲线，按 `Delta0` 和 `T` 切换。
3. `(U,Delta0)` 上的 `C_MB`、`Delta_min`、`Q_ad`、`eta(T)` 热图。
4. 代表性 `U` 的 `E0(phi)` 与 `E1-E0` 路径曲线，并标出最小能隙位置。
5. 一个自包含交互 HTML 和一组可引用的 PNG/PDF 静态图。

## 验收

- 中心 `Delta0=3` 数据与既有聚合表逐点一致。
- `eta` 只由 `Q/2` 计算，理想 `Q=2` 映射为 `eta=1`。
- 新结果通过现有 Hermiticity、残差、FHS 和实时范数/步长收敛检查。
- 输出明确区分旧数据、新算离散点和仅用于显示的插值。
