# Easy Goal Gates

Formal success requires five consecutive hash-linked N3 rounds, each with
correctness PASS, training convergence, frozen validation PASS, identifiable
objective, operator-equivalence bound <= 0.02, and excess patch-TV <= 0.02.
Only then may N4 five-bundle and N5 paired analysis proceed. An invalid gate,
missing manifest, unpublished staging round, or changed protocol yields an
incomplete classification rather than success.
