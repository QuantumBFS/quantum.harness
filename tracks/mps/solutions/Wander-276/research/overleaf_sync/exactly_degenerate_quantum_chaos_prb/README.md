# Paper I: Exactly Degenerate Quantum Chaos

This REVTeX project builds *Exactly Degenerate Quantum Chaos: Non-Abelian Quantum Geometry as a Probe*. The article reports finite-size, mechanism-resolved evidence and does not claim asymptotic or universal Geometric ETH.

Canonical outputs:

- `../../01_task_folder/task_05/script/output/paper1_prb_v13/exactly_degenerate_quantum_chaos_v13.pdf`
- `../../01_task_folder/task_05/script/output/paper1_prb_v13/exactly_degenerate_quantum_chaos_supplement_v13.pdf`
- `../../01_task_folder/task_05/script/output/paper1_prb_v13/delivery_audit_v13.json`

Rebuild from the repository root:

```bash
bash 01_task_folder/task_05/script/run_paper1_prb_delivery_v13.sh
```

The delivery command rebuilds the evidence registry and generated TeX assets, regenerates or validates all seven figures, runs the focused v13 tests, compiles the article and supplement twice, renders every page at 180 and 300 dpi, and verifies archived PDF hashes. The v1–v12 evidence base is byte sealed.

The original planning estimate was 14–18 pages. The later human request for a detailed complete PRB long form superseded that presentation estimate with a 20–26-page delivery contract; the final main text is 23 pages. This scope change does not change the registered scientific gates.
