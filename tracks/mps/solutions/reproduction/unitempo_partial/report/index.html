Model And Method

H(t)=Ω2σx+Ωcos(ωdt)σz

Figures 2-4 use an analytic zero-temperature Ohmic bath correlation function, system-bath coupling S = sigma_z, compression tolerance 1e-8, and UniformTEMPO.jl influence-functionals. The Figure 2 runs use alpha = 0.05, omega_c/Omega = 2.5, delta t = pi/(60 Omega), and bond dimension chi = 80. Figure 3 uses chi <= 120; the Figure 4 calculations use chi <= 80.

Provenance The solver scripts generate their trajectories from the model and analytic bath. Author-deposited curves were read only after generation to calculate the reported comparison metrics.

Limitations And Follow-Up

What is not claimed
  • The full 4 by 4 Floquet fixed-point solve selected a decoherence-free singlet and disagreed with the physical warm branch (RMSE 0.506). It is excluded from all validated results.
  • The issue is sector selection: collective Hamiltonian and bath coupling preserve triplet and singlet sectors, while the initial |00> state remains in the triplet sector.
  • A triplet-sector fixed-point solve agrees with the 200-period warm-up (RMSE 5.671e-4; maximum difference 6.714e-4), so future symmetric scans should impose that sector explicitly.
