# Source modules

- `lrtfim/couplings.py` implements the exact periodic Hurwitz-zeta reference
  coupling and an independent truncated image sum.
- `lrtfim/exponential_fit.py` implements constrained nonnegative exponential
  fitting and analytical periodization.
- `lrtfim/mpo.py` implements the finite custom TeNPy MPOGraph with direct and
  wrapped channels.

No DMRG implementation has been added.
