# Hydrodynamic Evidence Atlas

Current evidence state: **convergence gate not accepted**. The figures show numerical evidence in the frozen snapshot; they do not claim a mathematically exact scalar closure.

Each figure is exported as PNG, PDF, and editable-text SVG.
