The accepted manuscript's `1240 x 20 x 16 = 3.968 x 10^5` agrees with the
formal workload. The `3.398 x 10^5` value in the arXiv v1 text is not used.

The supplementary material gives the final 13 even operators, five odd
operators, stochastic optimization formula, and size-specific parameters. It
does not give the full set of 26 even operators used before screening, so the
26-to-13 screening cannot be reproduced from these materials alone.
