# 第四阶段：二维纯神经 VMCRG 替代协议 v1

## Material Passport

- Origin Skill: experiment-agent
- Origin Mode: plan
- Verification Status: UNVERIFIED
- Version Label: neural_replacement_protocol_v1

## 研究问题

在不使用13项线性块自旋偏置的条件下，神经能量能否独立表示二维 `L=45` VMCRG 的有效哈密顿量，并同时压平块自旋分布、保持固定点耦合和降低临界自相关时间？

## 表示

偏置严格写成

\[
V(\mu)=V_\theta(\mu),\qquad J_{13}=0.
\]

`V_theta` 使用平移、D4和Z2对称的半径3 shell MLP。输入直接来自块自旋，不把13个算符值输入网络。半径3覆盖已发表两体算符的全部位移范围。

## 实现门

1. 大感受野禁止分配指数增长的查找表；
2. 单块翻转只直接重算受影响的49个局域密度；
3. 直接局域能量差必须与全局重算一致；
4. 编译采样轨迹必须与参考采样逐步一致；
5. 原混合神经路径的全部测试必须继续通过。

## 执行顺序

1. `smoke`：使用满足半径3感受野最小要求的 `L=21`，只验证完整训练—验证—投影—消融—自相关链路，无统计结论；
2. `pilot`：`L=45`，判断表示和优化是否具有继续正式计算的可行性；
3. 只有 pilot 同时显示分布误差、13项投影残差和自相关均向正确方向变化，才允许锁定多种子 formal 协议。

禁止根据 pilot 结果直接修改正式门槛，也禁止把 pilot 的 `NOT_FORMAL` 当作挑战成功。

pilot 的模型、优化、验证、投影、消融和自相关随机流分别固定为 `202677101` 至 `202677106`，与前三阶段随机流分离。
