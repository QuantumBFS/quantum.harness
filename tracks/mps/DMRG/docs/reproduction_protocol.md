# 严格复现协议

## 总原则

每一阶段都必须同时满足：实现完成、独立测试通过、数值验收通过、参数来源可追溯。任何一项失败就停在该阶段定位根因。

## 阶段 0：证据冻结

输出：论文版本、Supplementary Material、算符表、参数表、版本差异表。

验收门：所有影响数值定义的参数均处于“已锁定”；无法从材料确认的项目明确标为未知。

当前状态：正文、accepted manuscript、Supplementary Material 和 arXiv 源文件均已取得并核对。公开材料能够锁定最终 13 个偶算符、5 个奇算符和 `L=45` 优化参数，但不能锁定作者原始 26 项坐标、随机种子和全部测量日程。因此阶段 0 对 13 项主流程通过，对原始 26 项严格筛选仍阻塞。

2026-07-14 的早期诊断结果已被后续正式实现取代，只保留为历史失败记录，不再代表当前状态。当前状态统一见 `docs/current_status.md`。

## 阶段 1：普通 Ising Metropolis

实现：周期边界、最近邻算符、单点翻转增量、随机 sweep、能量与磁化测量。

验收：

1. 任意构型、任意格点的增量 `delta S` 与翻转前后全量重算严格相等；
2. 全局自旋反演后 `S_nn` 不变、磁化变号；
3. `L=4` 的 MC 能量与全构型枚举结果在预设统计容差内一致；
4. 固定种子结果可重复。

## 阶段 2：`3 x 3` 多数规则

实现：块磁化、块自旋、原始翻转后的局部更新。

验收：

1. `5:4` 与 `4:5` 人工块判定正确；
2. 全局自旋反演时全部块自旋反演；
3. 每次接受翻转后，缓存块磁化/块自旋与全量重算严格一致。

## 阶段 3：单算符偏置最小闭环

只取块最近邻算符 `S_b=-sum_<IJ> sigma'_I sigma'_J`，偏置 `V_J=J S_b`。

验收：

1. 每个候选翻转的 `delta(H+V)` 与全量重算严格相等；
2. `J=0` 与普通 Metropolis 使用相同提议和随机数时轨迹一致；
3. 优化后 `mean(S_b)/N_b` 与 0 在独立运行误差内一致；
4. 冻结 `J` 后重新平衡和测量，不在非平稳优化轨迹上估计自相关。

注意：当前的单参数 Newton 轨迹只用于闭环诊断；在补充材料的精确随机优化规则锁定前，不作为论文结果。

## 阶段 4：26 项算符与筛选

先把补充材料的每个几何形状转成坐标集合，再由程序生成点群轨道并显式去重。为每个算符建立局部 incidence table。

验收：

1. 每个算符的平移/旋转/反射实例数与人工计数一致；
2. 局部 `delta S_alpha` 与全量重算逐项严格一致；
3. 在 `L=45`、论文参数下从 26 项筛出相同的 13 项；
4. 主要 `K'_alpha` 的符号、编号和量级一致。

阶段 4 对“作者原始 26 项严格筛选”仍未通过。后续多次 RG 只允许使用 Supplement 直接确认的最终 13 项，并必须明确标为 13 项主流程，不能反向宣称原始 26 项已经确认。

## 阶段 5：多次 RG 流

分别从 `K_nn=0.4355, 0.4360, 0.4365` 出发，在固定 `L x L` 晶格上把上一次输出耦合作为下一次输入，运行 5 次 VRG。

验收：0.4355 流向弱耦合，0.4365 流向强耦合，0.436 附近近似稳定；不同独立种子的结论一致。

## 阶段 6：RG Jacobian 与临界指数

在近似固定点冻结偏置后测量

`A[beta,gamma]=Cov(S_beta(sigma),S_gamma(sigma'))`

`B[alpha,gamma]=Cov(S_alpha(sigma'),S_gamma(sigma'))`

由 `A=T^T B` 解线性方程得到 `T`，不显式求逆。偶、奇区块分开处理。

验收：16 个独立 run 做 run-level jackknife/bootstrap；最大偶本征值接近 3，最大奇本征值接近 7.8452；同时报告矩阵条件数和重采样分布。

## 阶段 7：临界慢化

对相同固定点分别运行 biased/unbiased 冻结参数链，测量论文观测量的归一化时间自相关和积分自相关时间。

验收：给出窗口选择规则、误差与有效样本数，证明 biased 的相关时间显著下降，而非只比较曲线外观。

## 阶段 8：论文级交付

交付内容：源代码、固定配置、环境记录、原始种子、原始统计、图表生成脚本、验收报告、所有失败尝试及版本差异。逐比特复现只有在作者提供原始代码与种子时才可能；否则目标是统计意义复现。
