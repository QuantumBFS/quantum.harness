# 神经残差根因诊断协议 v1

## 目的

第二阶段已经确认：`13项线性偏置 + 神经残差` 没有比相同的13项线性偏置获得更短的自相关时间。第三阶段不重新训练，也不改变门槛，只回答为什么当前神经残差没有产生额外动力学收益。

## 冻结输入

- 第一阶段冻结的10个神经模型；
- 第二阶段三臂实验的80条链结果；
- `config/neural_root_cause_v1.json` 中预先固定的新随机流。

所有10个模型均纳入分析，包括原消融检验中的 PASS 和 FAIL，禁止按结果筛选模型。

## 检查一：精确局域谱

每个模型的3×3局域能量只有512种输入。枚举全部输入并作精确 Ising/Walsh 展开，报告常数、二体、四体、六体和八体以上分量的平方功率。该检查没有蒙特卡洛误差。

## 检查二：真实线性系综中的动力学尺度

对每个冻结模型运行4条新的线性偏置链：

- `L=45`；
- 热化500 sweeps；
- 500次测量，间隔1 sweep；
- 每次从当前构型中均匀抽取一个确实会改变3×3多数块自旋的微观翻转。

对同一提议计算：

1. 13项线性偏置能量差；
2. 神经残差能量差；
3. 加入神经残差前后的 Metropolis 接受概率差。

用模型—链两层 bootstrap 汇总：

- `RMS(ΔV_neural)/RMS(ΔV_linear)`；
- `mean |p_hybrid-p_linear|`。

若两者的 `mean+2SE` 分别低于0.1和0.01，则把当前失败归类为“神经残差的动力学扰动过小”。这些阈值在正式运行前固定，仅用于根因分类，不把第二阶段改判为通过。

## 检查三：静态目标与动力学结果的对应

对全部10个模型并列报告：

- held-out 变分消融量；
- 13项投影的验证 `R²`；
- 第二阶段 `τ_hybrid/τ_linear`；
- 两臂平均接受率之差。

相关性只作探索性诊断，不作为确认性门槛。

## 边界

本阶段不能证明纯神经网络可以替代13项算符，不能复现论文 Table I，也不能外推到三维自旋玻璃。
