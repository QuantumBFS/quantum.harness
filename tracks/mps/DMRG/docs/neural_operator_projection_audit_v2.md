# 神经能量算符与投影审计 v2

## 审计范围

本次只检查四个可能造成系统偏差的环节：论文最终 13 个偶算符的坐标、算符负号、D4/平移实例归一化，以及神经偏置到重整化哈密顿量的投影关系。

## 已确认项

1. `src/vmcrg_ref/operators.py` 的 13 组坐标与 `literature/SM.pdf` 第 3 页逐项一致，包括第 10 项 T 形四体算符。
2. 程序统一使用

   \[
   S_\alpha=-\sum_{c\in\mathcal O_\alpha}\prod_{i\in c}\sigma_i,
   \]

   因而正的最近邻耦合对应铁磁模型。
3. 每个 D4 方向和平移后的无向实例只计一次。每格点实例数依次为

   `2,2,2,4,2,2,4,1,1,4,8,4,4`。
4. 均匀目标分布下使用

   \[
   H'=-V_{\min}+C.
   \]

   投影输入是 `S/N` 和 `-V/N`。已知 13 维耦合的合成检验满秩，条件数约 15，最大恢复误差为 `4.9e-15`。因此不能翻转投影符号，也不能按算符实例数再次缩放。

## 已定位缺陷

旧纯神经表示先把半径 3 内同一 D4 shell 的所有自旋压成平均值。该表示能独立生成全部 7 个二体项，但不能独立生成全部 6 个四体项。对完整局部函数空间做结构秩检查时，单项相对残差为：

| 算符 | 结构残差 |
|---|---:|
| `even_08_square` | 0.9069 |
| `even_09_diamond` | 约 0 |
| `even_10_t` | 约 0 |
| `even_11_four` | 0.5304 |
| `even_12_four` | 0.6569 |
| `even_13_four` | 0.8589 |

所以旧架构即使无限训练也不能严格恢复完整耦合向量。五种子中稳定出现的四体投影失败不是坐标抄写、全局符号或最小二乘造成的。

## 修改

纯神经表示改为半径 3 的多尺度输入：

- 内层 `3x3` 保留 9 个逐点自旋，保证六个已发表四体形状可区分；
- 半径 2 和 3 仅保留 D4 shell 平均，覆盖全部已发表长程二体位移；
- 网络输出仍严格做 D4 群平均和全局 Z2 平均，并对所有格点中心求和；
- 固定线性偏置仍严格为零，没有把 13 个算符值作为网络输入。

旧 `shell` v1 表示和已锁定正式协议保留为历史复算入口，不覆盖旧结果。
