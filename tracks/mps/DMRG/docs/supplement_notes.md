## 随机优化规则

Supplement Eq. S2-S3 规定：

1. 采样偏置使用瞬时参数的运行平均 `J_bar`；
2. 梯度和 Hessian 都在 `J_bar` 对应的系综测量；
3. 瞬时参数按

   `J[n+1] = J[n] - mu * (gradient(J_bar[n]) + Hessian(J_bar[n]) @ (J[n]-J_bar[n]))`

   更新；
4. 最终输出运行平均 `J_bar`，不是最后一个瞬时 `J`；
5. 运行平均在轨迹长度的10%和20%处重置，以加快收敛。

Supplement Eq. S1 的印刷公式缺少 `1/n`，但上下文反复称其为 running average，图中平滑曲线也不可能是无界累计和。因此实现采用算术平均，并把该处记为补充材料排版遗漏。

## 仍然缺失

补充材料只列出了筛选后保留的13个偶算符，没有列出初始13个二体加13个四体的完整26项。因此无法严格复现“26项筛成13项”，但可以严格采用论文最终13项继续复现RG流和临界指数。

补充材料也没有显式写出点群求和和负号归一化。当前实现采用与各向同性平方晶格及正文正铁磁耦合一致的约定：对每个形状生成全部不同的 `D4` 方向和平移，每个无向实例只计一次，并定义 `S_alpha` 为这些乘积之和的负值。该约定必须通过论文耦合量级进一步验证。
