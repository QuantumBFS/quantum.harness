# 49-qubit PEPO/OLE 远端测试记录

更新日期：2026-07-30

## 结论

49-qubit PEPO 程序已经在真实 Slurm 节点上成功运行，并完成
`Dop={2,4,8,16,32,64,128,256,384,512}`、`χenv={16,32,64}` 的自适应扫描。所有
27 个 δ=0.15 执行记录成功，覆盖 26 个唯一参数点；重复的
`(Dop=8,χenv=64)` 两次结果只差 `3.04×10⁻¹⁸`。

当前最大参数点为：

```text
FPEPO(Dop=512, χenv=64) = 0.8225508376024053
ΔDop  = 0.00019707073422559063
Δχenv = 0.00018331834972928895 [Dop=512, χenv=32→64]
εPEPO = ΔDop + Δχenv = 0.0003803890839548796
```

`Dop=384→512` 的增量只有前一步的约 19.50%，经验误差和已经低于
`10⁻³` 目标。最大 `Dop` 的直接环境截面也已经补齐；但是
`χenv=16→32→64` 的结果非单调，且最新一步变化绝对值比前一步更大。因此：

> **49Q 执行链路验证通过，最大角点的双参数经验误差和已经达到
> `10⁻³` 目标；但 `χenv` 方向尚未出现稳定趋势。当前结果仍标记为 diagnostic，
> 不能作为 BP-TN baseline 的独立复现。**

## 问题定义

- 系统：49 个 active heavy-hex sites，对应有限 QASM 相互作用图；
- 电路：经审计的 73-layer、648-CZ echo circuit；
- QASM SHA-256：
  `1705197e7b1ebb02266600b3ddaba0d2c47a96de84c5895e2bb530728b815455`；
- 观测量：`O=Z52 Z59 Z72`；
- 扰动参数：δ=0.15；
- 目标：
  `F=2⁻⁴⁹ Tr[O C† O C]`；
- PEPO 演化截断：`evolution_cutoff=10⁻¹²`；
- 环境收缩截断：`contraction_cutoff=10⁻¹²`；
- 软件：quimb commit
  `3c89529fe0a3487133a3928201691161e110abdf`。

`Dop` 是 Heisenberg-picture 算符 PEPO 的最大虚拟键维数，控制算符纠缠的保留能力；
`χenv` 是最终二维张量网络近似收缩的环境键维数，控制收缩精度。

结果显示两个清晰特征：

1. 最大 `Dop=512` 的直接环境截面为
   `0.822454680→0.822367519→0.822550838`。相邻有符号变化依次为
   `−8.72×10⁻⁵` 和 `+1.83×10⁻⁴`。两步都低于 `10⁻³`，但序列非单调，
   且最新变化绝对值增大约 2.10 倍；因此环境方向的数值规模较小，却还不能
   判定趋势稳定。
2. `Dop=16→32→64→128→256→384→512` 的增量依次约为
   `4.49×10⁻¹`、`2.03×10⁻¹`、`7.85×10⁻²`、`2.26×10⁻²`、`1.01×10⁻³`、
   `1.97×10⁻⁴`。最新/前一步增量比约为 `0.1950`，且 `ΔDop<10⁻³`；
   operator-bond truncation 已通过本报告预先声明的经验精度目标。
3. 不能仅用最后两个递减比率进行 `Dop→∞` 外推。当前还没有足够稳定的渐近区间，
   任意指数或幂律拟合都会引入未受控的模型假设。

局部诊断量 `max_retained_tail_ratio=1.0` 是每次局部 SVD 中最后一个保留奇异值
与首个奇异值之比的最大值，不是严格的 discarded-weight 误差界。它与部分局部谱
没有明显衰减相容，也支持“当前 `Dop` 截断很强”的判断。

## 与 BP-TN baseline 的比较

采用已复现的 BP-TN 结果：

```text
FBP = 0.8183229131612796
εBP = 0.0044
|FPEPO − FBP| = 0.004227924441125741
```

当前 PEPO 值比 BP-TN 均值高约 `0.52%`，两者差值仍小于 BP-TN 的经验预算。
形式上，`|FPEPO−FBP|` 也小于
`εPEPO+εBP≈0.00478039`。这是有利的交叉方法信号，但还不能判定 agreement：
虽然经验误差和已通过数值阈值，最大角点的环境序列尚未稳定。PEPO 已在
`Dop=128→256` 之间越过本次 BP 均值，并在 `Dop=384→512` 继续升高，说明“最接近
BP 的 D”不能替代 PEPO 自身的收敛判据。按照预先声明的判据，只有内部收敛后
才能给出 agreement/disagreement；当前分类保持为 **diagnostic**。

作为背景，tracker 的两个公开 BP-TN raw 中心值分别为 `0.8202512915`
和 `0.8216584890`；当前 PEPO 分别高 `0.002300` 和 `0.000892`。
IBM Heron R3 的 `0.824` 是经过 δ=0 global rescaling 的量子硬件值，与当前
raw PEPO 的处理口径不同，只能作背景参考，不能作为直接收敛目标。

## δ=0 控制

完整 49Q 系统在 `δ=0`、`Dop=4`、`χenv=32` 时得到：

```text
Fδ=0 = 1.144729724987166×10⁻⁶
```

未经截断时，理想 echo 应给出 `Fδ=0=1`。这个低 `Dop` 控制远离 1，并不与
七量子比特 exact-oracle 验证冲突：小系统未截断 PEPO 在 δ=0 与 dense oracle
相差约 `6.9×10⁻¹⁵`；完整系统的低 `Dop` 控制进一步表明截断会摧毁 echo。

## 最终判断

当前阶段满足：

- 小系统算法/实现验证；
- 49Q 全链路可执行性验证；
- `Dop=512` 最大角点的直接 `χenv=16/32/64` 截面；
- `Dop=32→64→128→256→384→512` 增量连续减小的趋势证据；
- `Dop=512` 的经验 `ΔDop=1.97×10⁻⁴` 和
  `Δχenv=1.83×10⁻⁴`，使误差和为 `εPEPO=3.80×10⁻⁴<10⁻³`；
- 当前 PEPO 与公开 `χ=512` BP-TN 中心值相差 `8.92×10⁻⁴` 的交叉方法信号；
- 到当前上限 `Dop=512` 的 operator-bond 精度达标结论；
- 环境方向的相邻变化绝对值都低于 `10⁻³`。

当前阶段不满足：

- `Dop=512` 环境序列的稳定、单调收敛趋势；
- PEPO 对 BP-TN baseline 的独立 agreement；
- issue 119 的 PEPO baseline benchmark 完成条件。

若继续追求 PEPO 数值复现，最有信息量的下一步是
`Dop=512,χenv=128`。它用于判断 `χenv=32→64` 的反向变化是压缩收缩的正常
小幅波动，还是尚未进入稳定区间；只有新一步变化不再增大，预先声明的三项
内部收敛条件才会同时满足。当前主路线已经转向 BP-TN active G5/G6，因此不应
仅为了让有限 `Dop` 更接近某个 BP 中心值而无界增加 PEPO 计算。
