# 49-qubit PEPO/OLE 远端测试记录

更新日期：2026-07-29

## 结论

49-qubit PEPO 程序已经在真实 Slurm 节点上成功运行，并完成
`Dop={2,4,8,16,32,64,128,256,384}`、`χenv={16,32,64}` 的自适应扫描。所有
24 个 δ=0.15 执行记录成功，覆盖 23 个唯一参数点；重复的
`(Dop=8,χenv=64)` 两次结果只差 `3.04×10⁻¹⁸`。

当前最大参数点为：

```text
FPEPO(Dop=384, χenv=64) = 0.8223537668681797
ΔDop  = 0.0010106905997899762
Δχenv = 1.382546881401048×10⁻⁵  [来自 Dop=128 的完整 χenv 截面]
εPEPO = ΔDop + Δχenv = 0.0010245160686039867
```

`Dop=256→384` 的增量只有前一步的约 4.48%，`εPEPO` 仅比 `10⁻³` 目标高
约 2.45%。但最大 `Dop` 仍没有直接的 `χenv` 截面，因此：

> **49Q 执行链路验证通过，`Dop` 序列已非常接近经验收敛阈值，但在
> `Dop≤384` 范围内尚未完成双参数内部收敛；当前结果仍标记为 diagnostic，
> 不能作为 BP-TN baseline 的独立复现。**

## 问题定义

- 系统：49 个 active heavy-hex sites，对应有限 QASM 相互作用图；
- 电路：经审计的 73-layer、648-CZ echo circuit；
- QASM SHA-256：
  `1705197e7b1ebb02266600b3ddaba0d2c47a96de84c5895e2bb530728b815455`；
- 观测量：`O=Z52 Z59 Z72`；
- 扰动参数：δ=0.15；
- 目标：
  `F=2⁻⁴⁹ Tr[O C† O C]`；
- PEPO 演化截断：`evolution_cutoff=10⁻¹²`；
- 环境收缩截断：`contraction_cutoff=10⁻¹²`；
- 软件：quimb commit
  `3c89529fe0a3487133a3928201691161e110abdf`。

`Dop` 是 Heisenberg-picture 算符 PEPO 的最大虚拟键维数，控制算符纠缠的保留能力；
`χenv` 是最终二维张量网络近似收缩的环境键维数，控制收缩精度。

每个 cell 都处理了 3,937 个 causal gates，最终算符 support 扩展到全部 49 个
sites，实际最大虚拟键达到指定的 `Dop`。

结果显示两个清晰特征：

1. 最近的完整环境截面位于 `Dop=128`，其中 `χenv=16→32→64` 的变化依次约为
   `4.70×10⁻⁴` 和 `1.38×10⁻⁵`；最新变化已经低于 `10⁻³`，环境收缩不是
   当前主误差来源。`Dop=384` 只计算了 `χenv=64`，因此该环境误差只能作为继承
   proxy，不能直接证明最大角点的 `χenv` 收敛。
2. `Dop=16→32→64→128→256→384` 的增量依次约为
   `4.49×10⁻¹`、`2.03×10⁻¹`、`7.85×10⁻²`、`2.26×10⁻²`、`1.01×10⁻³`。
   最新/前一步增量比约为 `0.0448`，说明趋势显著改善；但 `ΔDop` 本身仍比
   目标高约 1.07%，operator-bond truncation 仍是当前经验误差的主项。
3. 不能仅用最后两个递减比率进行 `Dop→∞` 外推。当前还没有足够稳定的渐近区间，
   任意指数或幂律拟合都会引入未受控的模型假设。

局部诊断量 `max_retained_tail_ratio=1.0` 是每次局部 SVD 中最后一个保留奇异值
与首个奇异值之比的最大值，不是严格的 discarded-weight 误差界。它与部分局部谱
没有明显衰减相容，也支持“当前 `Dop` 截断很强”的判断。

## 与 BP-TN baseline 的比较

采用已复现的 BP-TN 结果：

```text
FBP = 0.8183229131612796
εBP = 0.0044
|FPEPO − FBP| = 0.0040308537069001504
```

当前 PEPO 值比 BP-TN 均值高约 `0.49%`，两者差值仍小于 BP-TN 的经验预算。
形式上，`|FPEPO−FBP|` 也小于
`εPEPO+εBP≈0.00542452`。这是有利的交叉方法信号，但还不能判定 agreement：
`εPEPO` 尚未通过内部阈值，而且最大角点缺少直接环境截面。PEPO 已在
`Dop=128→256` 之间越过本次 BP 均值，并在 `Dop=384` 继续升高，说明“最接近
BP 的 D”不能替代 PEPO 自身的收敛判据。按照预先声明的判据，只有内部收敛后
才能给出 agreement/disagreement；当前分类保持为 **diagnostic**。

作为背景，tracker 的两个公开 BP-TN raw 中心值分别为 `0.8202512915`
和 `0.8216584890`；当前 PEPO 分别高 `0.002102` 和 `0.000695`。
IBM Heron R3 的 `0.824` 是经过 δ=0 global rescaling 的量子硬件值，与当前
raw PEPO 的处理口径不同，只能作背景参考，不能作为直接收敛目标。

## δ=0 控制

完整 49Q 系统在 `δ=0`、`Dop=4`、`χenv=32` 时得到：

```text
Fδ=0 = 1.144729724987166×10⁻⁶
```

未经截断时，理想 echo 应给出 `Fδ=0=1`。这个低 `Dop` 控制远离 1，并不与
七量子比特 exact-oracle 验证冲突：小系统未截断 PEPO 在 δ=0 与 dense oracle
相差约 `6.9×10⁻¹⁵`；完整系统的低 `Dop` 控制进一步表明截断会摧毁 echo。

## 最终判断

当前阶段满足：

- 小系统算法/实现验证；
- 49Q 全链路可执行性验证；
- `χenv≤64` 的环境收缩稳定性证据；
- `Dop=32→64→128→256→384` 增量连续减小的趋势证据；
- 当前 PEPO 与公开 `χ=512` BP-TN 中心值相差 `6.95×10⁻⁴` 的交叉方法信号；
- 到当前上限 `Dop=384` 的诚实近阈值、但未收敛结论。

当前阶段不满足：

- `εPEPO≤10⁻³`；
- PEPO 对 BP-TN baseline 的独立 agreement；
- issue 119 的 PEPO baseline benchmark 完成条件。

若继续追求 PEPO 数值复现，最有信息量的下一步是
`Dop=512,χenv=64`。若该点使 `ΔDop` 达标，再在同一 `Dop=512` 角点补
`χenv=32`，形成直接环境截面。仅给 `Dop=384` 补环境点不能让当前经验预算
通过，因为现有 `ΔDop` 本身已略高于 `10⁻³`。无论下一步如何，都不能以
“当前数值最接近 BP-TN”替代 PEPO 自身的精度判据。
